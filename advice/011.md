# 3. B0.4a 不要再把“全动作 ε-optimal certificate”作为执行必要条件

这是最关键的架构调整。

当前 full certificate 要证明：

[
U_{a,b}\le\epsilon,\qquad
\forall b\neq a.
]

这相当于解决一个 best-arm identification 问题。

但实际部署根本不需要证明：

> “这个动作接近所有动作中的最优。”

只需要证明：

> **“这个动作不会比我本来会执行的 base action 差。”**

令 base 当前动作：

[
a_b=\pi_b(x,h).
]

定义：

# [ \Delta_{a,b}

## Q_a^{\pi_b}(x,h)

Q_{a_b}^{\pi_b}(x,h).
]

成本最小化，因此只要：

[
\boxed{
U_{a,a_b}<0
}
]

就能安全地执行 candidate (a)。

否则：

[
\boxed{
a_{\rm exec}=a_b.
}
]

也就是：

# [ a_{\rm exec}

\begin{cases}
a,&U_{a,a_b}<0,\
a_b,&\text{otherwise}.
\end{cases}
]

这比 full ε-optimal certificate 容易得多。

原因也很直接：原来需要同时排除约 (O(|A|)) 个 challengers；现在只需要证明：

[
a \prec a_b.
]

# 4. 这会产生一个比 B0.4 更强的理论结果

如果：

# [ V^{\pi_b}(x)

Q^{\pi_b}(x,\pi_b(x)),
]

且新策略每个状态选择的动作都满足：

[
Q^{\pi_b}(x,\pi'(x))
\le
V^{\pi_b}(x),
]

那么对于当前 finite acyclic evidence DAG，在 cost-minimization 口径下：

[
\boxed{
V^{\pi'}(x)\le V^{\pi_b}(x).
}
]

这是标准 policy-improvement 型结论。

所以 B0.4a 可以正式形成：

### High-probability certified policy improvement

若所有 override certificate 同时正确，则：

[
\boxed{
J^{\pi_{\rm CPI}}
\le
J^{\pi_b}.
}
]

这样论文叙事就从：

> “我大概找到一个 ε-optimal action”

升级成：

> **“只有统计证据足够时才偏离可靠的基策略。”**

这和分布式通信/感知系统的实际逻辑也更吻合。

# 5. 但要注意 episode-level (\delta)，不能每个 decision 都重新花 0.05

例如第 (t) 个实际 acquisition decision 使用：

# [ \delta_t

\frac{6\delta_{\rm episode}}
{\pi^2t^2}.
]

于是：

# [ \sum_{t=1}^\infty\delta_t

\delta_{\rm episode}.
]

decision 内如果同时检查 (K_t) 个 candidate-vs-base pair，再设：

# [ \alpha_{a,t}

\frac{\delta_t}{K_t}.
]

那么可以得到真正的 episode-level：

[
P(
\text{all executed overrides valid}
)
\ge1-\delta_{\rm episode}.
]

这个最好在 B0.4a 就做，不要留到 B0.6。

# 6. Persistent incumbent 也应该在这里一起落地

当前 planner 每轮顶部仍然可以由 raw running means 重新决定 candidate。B0.4r 已经诚实注明了这一点。

B0.4a 可以改成：

[
a_{\rm inc}^{(0)}=a_b.
]

之后 challenger (c) 只有在：

[
\boxed{
U_{c,a_{\rm inc}}<0
}
]

时才替换 incumbent：

[
a_{\rm inc}\leftarrow c.
]

因此 candidate trajectory 从：

[
\text{raw mean flips}
]

变成：

[
\text{certified monotone improvement chain}.
]

如果：

[
a_0=a_b,;
a_1,;
a_2,\ldots
]

则在 confidence event 上：

[
Q_{a_{k+1}}^{\pi_b}
<
Q_{a_k}^{\pi_b}.
]

这是非常干净的结构。

# 7. VoI-base 也应该做，但先定义得简单

建议：

# [ Q_a^{(1)}

c_a+
E[
R_{\rm stop}(X')
\mid x,a
].
]

STOP：

# [ Q_{\rm stop}^{(1)}

R_{\rm stop}(x).
]

于是：

# [ \boxed{ a_{\rm VoI}(x,h)

\arg\min_{a\in A_h^+(x)}
Q_a^{(1)}.
}
]

也可以写成信息价值：

# [ \operatorname{VoI}_a(x)

## R_{\rm stop}(x)

## E[R_{\rm stop}(X')|x,a]

c_a.
]

仅当：

[
\operatorname{VoI}_a>0
]

才 acquisition。

它的优点是：

- objective-consistent；
- 自动考虑 header/setup cost；
- 自动考虑当前 posterior；
- 自动考虑 message resolution；
- 不需要 MAPPO/NN；
- 复杂度只是一层 conditional expectation。

非常适合作为 rollout base。

# 8. B0.4a 最关键的 Gate 不应该是 certification rate 本身

我建议 B0.4a 只回答四个科学问题：

**第一，fallback 是否真正消除了 uncertified tail？**

当前 empirical fallback：

[
P(\mathrm{gap}\le2)\approx0.821.
]

需要比较：

[
\text{Empirical-best},
\quad
\text{SNR-base fallback},
\quad
\text{VoI-base fallback}.
]

重点看：

[
E[\mathrm{gap}],
\quad
P(\mathrm{gap}>2),
\quad
P(\mathrm{gap}>4).
]

**第二，override 是否真的带来收益？**

报告：

[
P(\text{override})
]

和：

[
\boxed{
E[
Q_{a_b}-Q_{a_{\rm override}}
\mid\text{override}
].
}
]

如果 override rate 只有 1%，即使全部正确，也说明复杂 planner 没多大实际价值。

**第三，certified override 是否绝对安全？**

在 N=4 exact oracle 上检查：

[
Q_a^{\pi_b}
\le
Q_{a_b}^{\pi_b}.
]

报告 violations + binomial U95。

**第四，VoI-base 本身有多强？**

这非常重要。

如果：

[
\text{VoI-base}\approx\text{CR planner},
]

那最终论文应该强调：

> feedback granularity + conditional VoI

而不是硬包装 rollout planner。

反过来，如果 CPI 在 VoI-base 之上还有明显增益，那么 pairwise planning 才真正获得独立算法价值。
