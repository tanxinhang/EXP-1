可以，而且在“**不增加新模块、不继续横向扩展**”这个约束下，我反而更建议对当前系统做一次纵向收敛。重新对照 `SystemModel`、`run_mvsc03e.py`、`run_mvsc04.py` 和 C5 后，我认为现阶段最重要的优化不是继续加机制，而是把**现有 O-PEF/GPE 主算法真正实现到它自己已经定义的数学语义**。

## 一、当前最值得修的核心：GPE 实际上没有完整实现现有 Depth-2

`SystemModel §24` 对 O-PEF-2 已经写得很明确：

Qa(2)(x)=ca+Ex′∣x,a[min⁡{R(x′),min⁡b[cb+E[R(x′′)∣x′,b]]}].Q_a^{(2)}(x) = c_a+ \mathbb E_{x'|x,a} \left[ \min \left\{ R(x'), \min_b \left[ c_b+\mathbb E[R(x'')|x',b] \right] \right\} \right].

这里第二步是

min⁡b\boxed{\min_b}

也就是说，看完第一条实际 evidence 后，第二次通信可以重新选择**任意可行动作**。

但当前 `GPE-EA-het` 实际做的是：

```text
第一步：(i,r→s)
第二步：仍然只能在同一个 UAV i 上选择 t>s
```

`conts` 明确只枚举同一 UAV 的更高 precision；而且当 `s==r_max` 时直接按 terminal one-step 处理。

这意味着当前算法实际上是：

self-refinement Depth-2\boxed{\text{self-refinement Depth-2}}

而不是系统模型定义的：

global-action Depth-2.\boxed{\text{global-action Depth-2}}.

这是现在最应该优化的地方，而且**不需要新增任何模块**。

# 二、把现有 GPE 改成真正的 Branch-Adaptive Depth-2

设当前状态和剩余预算为 (x,h)(x,h)，第一动作

a=(i,ri→s),ca≤h.a=(i,r_i\rightarrow s), \qquad c_a\le h.

获得实际 message 后进入随机状态 X′X'，剩余预算：

h′=h−ca.h'=h-c_a.

在 X′X' 上，对**当前所有 UAV 的全部可行动作**

A(X′,h′)={(j,rj→u):u>rj, cj,rj→u≤h′}\mathcal A(X',h') = \{ (j,r_j\rightarrow u): u>r_j,\ c_{j,r_j\to u}\le h' \}

重新计算 one-step action value：

Q1(b∣X′)=cb+E[R(X′′)∣X′,b].Q_1(b|X') = c_b+ \mathbb E[ R(X'')|X',b ].

于是现有 O-PEF-2 应真正实现为

Q2(a∣x,h)=ca+E[min⁡{R(X′),min⁡b∈A(X′,h′)Q1(b∣X′)}].\boxed{ Q_2(a|x,h) = c_a+ \mathbb E \left[ \min \left\{ R(X'), \min_{b\in\mathcal A(X',h')} Q_1(b|X') \right\} \right]. }

这一个修改就同时允许：

UAV i coarse probe→继续 refine i,\text{UAV }i\text{ coarse probe} \rightarrow \text{继续 refine }i,

也允许

UAV i coarse probe→转向 UAV j,\text{UAV }i\text{ coarse probe} \rightarrow \text{转向 UAV }j,

甚至：

i 已经直接发到8 bit→根据结果决定是否请求 j.i\text{ 已经直接发到8 bit} \rightarrow \text{根据结果决定是否请求 }j.

所以当前代码中“`s=r_max` ⇒ terminal”的处理，在完整 Depth-2 语义下也应该取消——**某个 UAV 到达最高精度，并不意味着整个网络的信息获取过程已经 terminal。**

# 三、这里可以得到一个非常漂亮的严格理论结果

定义 Myopic one-step：

Q1(a∣x,h)=ca+E[R(X′)].Q_1(a|x,h) = c_a+\mathbb E[R(X')].

再定义第一步实际 message 到达后的最优 continuation advantage：

Δ(X′,h′)=[R(X′)−min⁡b∈A(X′,h′)Q1(b∣X′)]+.\Delta(X',h') = \left[ R(X') - \min_{b\in\mathcal A(X',h')} Q_1(b|X') \right]_+.

那么直接代入上式，有：

Q2(a∣x,h)=Q1(a∣x,h)−E[Δ(X′,h−ca)].\boxed{ Q_2(a|x,h) = Q_1(a|x,h) - \mathbb E[\Delta(X',h-c_a)]. }

这是**精确恒等式**，不是近似。

因此立即得到：

Q2(a)≤Q1(a)\boxed{Q_2(a)\le Q_1(a)}

对每一个相同第一动作都成立。

严格小于的充要激活条件则是：

P{Δ(X′,h−ca)>0}>0.\boxed{ P\{ \Delta(X',h-c_a)>0 \}>0. }

这比现在只观察：

> GPE 和 Myopic 最后 E[B] 是否不同

强很多。

因为以后可以直接回答：

> conditional planning 为什么有价值？

答案是：

E[Δ]>0.\mathbb E[\Delta]>0.

如果没有价值：

E[Δ]=0.\mathbb E[\Delta]=0.

不再需要依赖 Monte Carlo 猜原因。

# 四、当前 GPE=Myopic 的“零价值”也能进一步分解

把第二动作分成两类：

Aself={(i,s→t)},\mathcal A_{\rm self} = \{ (i,s\rightarrow t) \},

和

Across={(j,rj→u):j≠i}.\mathcal A_{\rm cross} = \{ (j,r_j\rightarrow u):j\neq i \}.

当前实现实际上只计算：

Δself(X′)=[R(X′)−min⁡b∈AselfQ1(b∣X′)]+.\Delta_{\rm self}(X') = \left[ R(X') - \min_{b\in\mathcal A_{\rm self}} Q_1(b|X') \right]_+.

真正系统应该计算：

Δall(X′)=[R(X′)−min⁡b∈Aself∪AcrossQ1(b∣X′)]+.\Delta_{\rm all}(X') = \left[ R(X') - \min_{b\in\mathcal A_{\rm self}\cup\mathcal A_{\rm cross}} Q_1(b|X') \right]_+.

显然：

Δall≥Δself.\boxed{ \Delta_{\rm all}\ge\Delta_{\rm self}. }

因此：

Gswitch=E[Δall−Δself]≥0.\boxed{ G_{\rm switch} = \mathbb E[ \Delta_{\rm all}-\Delta_{\rm self} ] \ge0. }

这个量可以定义为：

> **evidence-conditioned UAV switching gain**

它不是新增模块，而是对现有 O-PEF-2 中已经存在的 min⁡b\min_b 做严格展开。

这其实比我上一轮建议立即引入新的 `b_ref` 参数更合适。**在你明确要求不增加模块之后，应该先把现有 Depth-2 做完整，而不是靠修改成本参数强行制造 progressive gain。**

# 五、现有 Phase-Envelope 不删除，但要重新定位

现在 `phase_boundary.py` 的 generalized identity：

Qprogs,t−Qdirt=E[min⁡{Yi,s,t,b0,i}]Q_{\rm prog}^{s,t} - Q_{\rm dir}^{t} = \mathbb E[ \min\{Y_{i,s,t},b_{0,i}\} ]

本身数学是成立的，而且当前实现已经支持任意

r<s<tr<s<t

和 heterogeneous affine cost。

所以不要推翻。

但是应该明确：

Phase-Envelope=same-UAV conditional-refinement subproblem\boxed{ \text{Phase-Envelope} = \text{same-UAV conditional-refinement subproblem} }

而：

GPE=network-wide conditional continuation policy.\boxed{ \text{GPE} = \text{network-wide conditional continuation policy}. }

这样层次反而更漂亮：

global Depth-2⊃same-UAV phase structure.\text{global Depth-2} \supset \text{same-UAV phase structure}.

需要特别注意：一旦 GPE 第二步允许跨 UAV，原有

g=E[min⁡(Y,b0)]g=\mathbb E[\min(Y,b_0)]

就**不能继续被当成整个 first-action 的全局 dominance certificate**。

因为 probe 后可能：

i→j,i\rightarrow j,

而 direct 后也可能：

i→k.i\rightarrow k.

原 theorem 没有计算这些 cross-UAV continuation。

所以建议：

- Phase-envelope 保留为解析机制解释；
- 保留 same-UAV pruning 的诊断；
- 不再把它用于证明整个 global Depth-2 action 被支配。

这是很重要的数学边界。

# 六、计算复杂度可以在现有 GPEMemo 内部解决，不需要新增模块

完整 Depth-2 最大的问题当然是计算量，但可以利用一个非常强的 exact pruning。

在 branch state x′x' 上：

Q1(b∣x′)=cb+E[R(X′′)∣x′,b].Q_1(b|x') = c_b+ E[R(X'')|x',b].

因为：

R(X′′)≥0,R(X'')\ge0,

所以：

Q1(b∣x′)≥cb.\boxed{ Q_1(b|x')\ge c_b. }

当前 STOP value 是：

R(x′).R(x').

因此如果：

cb≥R(x′),c_b\ge R(x'),

则必然：

Q1(b)≥R(x′),Q_1(b)\ge R(x'),

这个动作绝不可能优于 STOP。

所以第二阶段可以直接执行：

cb≥R(x′)⇒exact prune.\boxed{ c_b\ge R(x') \Rightarrow \text{exact prune}. }

进一步，把 candidate 按 cbc_b 从小到大排序，当前已经得到 best value VbestV_{\rm best} 时，只要：

cb≥Vbest,c_b\ge V_{\rm best},

后面的所有动作都不用计算，因为：

Q1(b)≥cb≥Vbest.Q_1(b)\ge c_b\ge V_{\rm best}.

这是严格 branch-and-bound，不是 heuristic。

因此原来可能需要：

O(∣A1∣×∣supp⁡(X′)∣×∣A2∣)O(|A_1|\times |\operatorname{supp}(X')|\times|A_2|)

的计算，在真实状态上会被大量裁掉。

而且完全可以继续复用现在 `GPEMemo` 的：

- structure cache；
- Q cache；
- quantizer transition template。

不需要新建 planner。

# 七、第二个必须优化的现有模块：C5 mismatch fidelity

这个还是 P0。

当前 `NestedQuantizer` 的边界通过 mixture conditional median 构造，因此量化边界本身依赖 sensing model γ\gamma。

C5 当前比较：

gmodel(x,Ω)vsgtrue(x,Ω),g_{\rm model}(x,\Omega) \quad\text{vs}\quad g_{\rm true}(x,\Omega),

但存在两个问题。

第一，同一个 message index mm 在 `qu_model` 和 `qu_true` 中对应的物理 LLR 区间不同。

第二，当前 `pruning_fidelity()` 对 true planner 仍然传入 model reachable state 的同一个 `om`。而实际上同一个物理 message state xx 下：

Ωmodel(x)≠Ωtrue(x).\Omega_{\rm model}(x) \neq \Omega_{\rm true}(x).

因此正确比较应该冻结 deployment partition：

Bdeploy=Bmodel,\mathcal B^{deploy} = \mathcal B^{model},

然后在这些完全相同的 cells 上重新计算：

Ptrue(M=m∣Hh),P_{\rm true} ( M=m|H_h ),

得到：

ℓtrue(r)(m)=log⁡Ptrue(M=m∣H1)Ptrue(M=m∣H0).\ell_{\rm true}^{(r)}(m) = \log \frac{ P_{\rm true}(M=m|H_1) }{ P_{\rm true}(M=m|H_0) }.

然后：

Ωtrue(x)=log⁡π1π0+∑iℓi,true(mi).\Omega_{\rm true}(x) = \log\frac{\pi_1}{\pi_0} + \sum_i\ell_{i,\rm true}(m_i).

最终再比较：

gmodel(x,Ωmodel)g_{\rm model}(x,\Omega_{\rm model})

与

gtrue(x,Ωtrue).g_{\rm true}(x,\Omega_{\rm true}).

这样 C5 中所谓 29.1% false-prune / 40% miss-prune 才具有严格物理语义。

不需要新模块，只需要给现有 `NestedQuantizer` 增加一个：

```text
bounds_override=None
```

之类的可选入口，或者在现有 C5 内复用 model bounds 重新算 PMF。

# 八、第三个优化：C4 的 link cost 保留，但物理映射应该收紧

当前代码文档定义：

κi≡1Ri,\kappa_i\equiv \frac1{R_i},

这是正确的通信解释。

但实际 `link_params()` 是：

b0,i=12+8(1−qi),b_{0,i} = 12+8(1-q_i),κi=0.8+0.4(1−qi).\kappa_i = 0.8+0.4(1-q_i).

也就是说两个 cost 参数实际上都是对一个抽象 rank qiq_i 做线性映射。

数学上没错，但通信物理上还比较 surrogate。

在**不增加通信模块**的情况下，可以只修改当前 `link_params()`：

先由抽象 link quality 产生 communication SINR：

Γic,dB=Γmin⁡+qi(Γmax⁡−Γmin⁡),\Gamma_i^{c,\rm dB} = \Gamma_{\min} + q_i(\Gamma_{\max}-\Gamma_{\min}),

再使用：

Ri=Wlog⁡2(1+Γic),R_i = W\log_2(1+\Gamma_i^c),

于是：

κi=BunitRi.\boxed{ \kappa_i = \frac{B_{\rm unit}}{R_i}. }

控制开销则独立写成：

b0,i=BctrlRictrl,b_{0,i} = \frac{B_{\rm ctrl}}{R_i^{ctrl}},

或者第一阶段直接保持：

b0,i=b0b_{0,i}=b_0

为公共 control duration。

也就是说，**不要强迫 setup overhead 和 payload rate 使用同一个线性 q 映射**。

这会让通信解释更牢固，同时完全不增加研究变量。

但建议这一步要在 full Depth-2 修正之后单独做，不能两个改动一起跑，否则因果解释又混了。

# 九、量化器暂时不要先改

虽然现有 nested conditional-median quantizer 并不是 detection-optimal，它优化的是 mixture-mass balance，而不是 Bayes-risk reduction，但我目前**不建议立即动这一块**。

原因很简单：

现在已经有一个明确的 GPE semantic gap。

应该先固定：

Qi(r)Q_i^{(r)}

不变，比较：

旧 self-only GPE\text{旧 self-only GPE}

与：

正确 global Depth-2 GPE.\text{正确 global Depth-2 GPE}.

如果此时已经出现：

Gswitch>0G_{\rm switch}>0

以及 pathwise action differences，那么机制已经被激活。

只有如果完整 Depth-2 仍然：

Δall=0\Delta_{\rm all}=0

才进入第二轮，对现有 `NestedQuantizer` 做 task-aware nested split。

否则同时改 planner 和 quantizer，会让论文无法回答“性能提升到底来自哪里”。

## 最终建议

当前系统不需要继续“加东西”。

最应该做的是把现有研究主线从：

first action global+second action self-only\text{first action global} + \text{second action self-only}

修正为真正已经在 `SystemModel` 中定义的：

realized-message-conditioned global evidence acquisition.\boxed{ \text{realized-message-conditioned global evidence acquisition}. }

这一步的意义非常大，因为它使 O-PEF 的核心不再只是：

> 一个 UAV 先发粗消息，再决定是否让它自己发得更细，

而变成：

> **收到某 UAV 的实际软证据之后，重新判断下一单位 U2U airtime 应投给哪个 UAV、提升哪个 precision，或者停止。**

这才真正对应你最开始定义的：

UAV selection+precision selection+realized-message adaptation+communication-aware stopping.\boxed{ \text{UAV selection} + \text{precision selection} + \text{realized-message adaptation} + \text{communication-aware stopping}. }

而且数学上可以用

Q2=Q1−E[Δ]\boxed{ Q_2 = Q_1- E[\Delta] }

和

Gswitch=E[Δall−Δself]\boxed{ G_{\rm switch} = E[\Delta_{\rm all}-\Delta_{\rm self}] }

给出非常干净的理论支撑。

**我会把这一项定为当前最高优先级 P0，而不是继续加 B1、session 模块或新的 robustness 模块。** C5 的 mismatch credibility 修复紧随其后，C4 的物理 rate mapping 再作为第三优先级。这样既不扩系统，又比继续堆模块更有可能把现有工作真正收敛成一个有理论辨识度的论文主算法。
