## 1. 当前 B0.6-pre 最重要的三个问题

| 级别     | 问题                                                         | 影响                                                         | 建议                                                         |
| -------- | ------------------------------------------------------------ | ------------------------------------------------------------ | ------------------------------------------------------------ |
| **P0-1** | `reachable_states()` 只生成 (x)，但 G0/G1/G2 对所有非根状态仍用固定 `h=40` | 实际 CPI 的状态是 **((x,h))**；发生过反馈后 (h) 应减少。现在测试了很多“证据状态可达、预算状态不可达”的点 | 改成 `reachable_augmented_states -> (x,h,t)`，每次真实扣除 setup+payload |
| **P0-2** | G0 最终选 **SNR base**，G1 formal certification 却使用 `cr_voi4`，G2 又使用 SNR | 四个 Gate 没有验收同一个冻结 policy                          | B0.6 冻结 SNR anchor 后，G1 也必须重跑 SNR                   |
| **P0-3** | G3 用 `W=250`，因为 30 个状态恰好 `24/30=0.80`               | 但 W=500 又降到 0.7667；没有 CI，不能称为稳定 sample-complexity crossing | 用 held-out + CI 决定 (w_{\rm ep})，不能用 point estimate 首次过线 |

第一条尤其重要。代码明确强调 base 是 budget-aware augmented-state policy，但 `reachable_states()` 只返回 (x)，随后却调用 `exact_qa_pi_b(..., x, 40)`。这与最终 receding episode 中 (h_t=H-C_t) 的部署状态并不一致。

第二条也属于真正的 credibility issue：B0.4a 原本就把 SNR/VoI 区分成不同 anchor，B0.6-pre 又选择了 SNR，但 formal G1 仍然认证 VoI。

## 2. 当前 “PASS” 的统计强度其实还不够

G0 的最好结果是：

[
25/30=0.8333.
]

但 25/30 的普通 Wilson 95% 区间大约是

[
[0.664,;0.927].
]

所以不能统计性地声称

[
P(\mathrm{gap}\le2)\ge0.80.
]

G2 更明显：

[
10/10=1.0,
]

但只有 **10 个 N=8 states**；10/10 的 Wilson 95% 下界大约只有 0.72，仍低于 Gate 的 0.75。当前报告中的 G0/G2 因而更适合作为 **engineering acceptance**，不是 statistical certification。

此外 `reachable_states()` 没有去重，而且随机深度是 0/1/2；因此约三分之一抽样天然可能直接是 root。G1 的 gap 列表中 `17.2 / 21.5 / 21.9` 多次重复，也已经暗示有效独立状态数低于表面的 15。

### 建议 B0.6-pre-r 只改四件事

1. 生成真实 ((x,h,t)) reachable states；
2. 去重，同时增加一个 **on-policy occupancy** state set；
3. 全部冻结成 **SNR anchor**；
4. Gate 改成 CI 判定。

例如：

[
\mathrm{LCB}_{95}
\left[P(\mathrm{gap}\le2)\right]\ge0.8,
]

同时对 paired gap

[
D_s=
\mathrm{gap}^{CPI}_s-\mathrm{gap}^{base}_s
]

要求

[
\mathrm{UCB}_{95}(E[D_s])<-1.
]

G2 同理。

这一步**不要再优化 CPI 本身**。

# 4. 接下来直接做 B0.6，但实验口径必须一次冻结

B0.6 最终真正应该检验的是：

[
\boxed{
\begin{aligned}
P_{FA}^{CR}&\le\alpha,\
P_{MD}^{CR}&\le\beta,\
E[B^{CR}]&<E[B^{Direct8}]
\end{aligned}}
]

而 **POTS 应作为第二 comparator**。

原因非常现实：B0.1a 已经得到：

- Direct8-Ordered：约 **110.5 bits**
- 1bit-POTS：约 **277.1 bits**

在 matched operating point 下 Direct8 已经非常强。

而 B0.3c 中 CR 的低通信量：

[
54.3\ {\rm bits}
]

对应的 (P_D=0.6257)，Direct8 是 (59.4) bits、(P_D=0.6530)，本来就没有 matched。

所以：

> **打赢 POTS 不够。B0.6 的论文生死点就是能否统计显著地打赢 optimized Direct8。**

------

## 5. 我建议 B0.6 使用这个协议

物理随机量必须 CRN：

[
W_e=(H_e,M_{1,e}^{(8)},\ldots,M_{N,e}^{(8)})
]

同一 episode 给 CR、Direct8、POTS 使用同一个 physical world；但各算法内部 planner RNG 独立。

把 **radio cost** 和 **planning cost** 完全分开：

# [ B_{\rm radio}

\sum_t
(b_{\rm setup}+\Delta r_t),
]

而 CPI 的 `worlds/rollouts`：

[
W_{\rm CPI}
]

只能作为 computational complexity，绝对不能计入通信 bit。

最终 bit gain 用 episode-paired difference：

[
D_e^{D8}=B_e^{CR}-B_e^{D8}.
]

真正的 PASS 应要求：

[
\boxed{
U_{95}!\left(E[D_e^{D8}]\right)<0
}
]

而不是简单比较两个 sample mean。

QoS 同样使用单侧 CI：

[
U_{95}(P_{FA}^{CR})\le\alpha,
\qquad
U_{95}(P_{MD}^{CR})\le\beta.
]

最终只有三种结果：

- **PASS**：两个 QoS UCB 都达标，且 bit-difference UCB < 0；
- **FAIL**：CI 已明确证明 QoS 不满足或 CR 不比 Direct8 省；
- **UNCERTAIN**：CI 跨边界，继续增加 fresh samples。

不要再把 UNCERTAIN 当 FAIL。

------

# 6. 样本量也建议改

当前 B0.6 设想的 800 episodes，如果 (P(H_0)=P(H_1)=0.5)，实际上只有约：

[
N_0\approx400,\quad N_1\approx400.
]

如果真实 (P_{FA}\approx0.04)，400 个 (H_0) 样本的单侧 95% UCB 仍接近 **0.059**，很难认证：

[
P_{FA}\le0.05.
]

因此不要随机混合 H0/H1。

建议直接做 **stratified evaluation**：

[
N_0=N_1.
]

初始：

[
N_0=N_1=1500
]

然后 CI 未决再 sequential escalation 到 2000/3000/5000。

这样检测 QoS 的 sample complexity 和 CPI planner worlds 是两回事，不应混在一起。

# 7. 论文层面的一个关键判断

B0.4b 已经告诉我们 root：

[
b^\star(x_0)=7,
]

而当前：

[
b_{\rm setup}=16.
]

所以 **根状态天然处于 direct-packetization 倾向区域**。真正能够让 CR 战胜 Direct8 的机制，必须来自后续状态中出现的

[
b^\star(x)=\infty
]

或较大的 phase boundary——也就是：

[
\boxed{\text{state-dependent switching}}
]

而不是“progressive 永远优于 Direct8”。

这其实使 B0.6 更有科学意义。

如果 B0.6 最终：

[
E[B]^{CR}<E[B]^{Direct8},
]

论文主线就非常完整：

[
\text{phase-transition theorem}
\rightarrow
\text{state-adaptive packetization}
\rightarrow
\text{paired certified acquisition}
\rightarrow
\text{matched-QoS bit saving}.
]

如果最终：

[
E[B]^{CR}\ge E[B]^{Direct8},
]

也不要继续修算法把结果“调赢”。这时诚实结论应该是：

> **phase transition 与 state-dependent adaptive packetization 理论成立，但在当前 (b_{\rm setup}=16) regime 下，optimized direct packetization 已接近或达到最优通信工作区间。**

然后再做 **预先声明为 secondary analysis** 的

[
b_{\rm setup}\in{0,4,8,16,32}
]

regime map，验证理论预测的 crossover。

## 最终建议

现在的顺序我建议调整成：

[
\boxed{
\text{B0.6-pre-r 小可信度补丁}
\rightarrow
\textbf{B0.6 matched-QoS}
\rightarrow
\begin{cases}
\text{PASS}: B0.5/论文收口\
\text{FAIL}: phase-regime analysis\
\text{UNCERTAIN}: 扩样
\end{cases}}
]

**不要再对 B0.4/CPI 做算法升级。**

`f2bb395` 最大的成果已经不是“证明算法必然能赢”，而是说明 **CPI acquisition 在计算上确实可运行**。现在必须让 B0.6 回答唯一剩下的核心问题：**在严格 matched QoS 下，多粒度反馈到底能不能统计显著地少于 Direct8 的 radio bits。**
