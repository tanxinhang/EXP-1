## 审计结论

**先不要直接跑当前定义的 B0.7-G2。**

B0.7-G0/G1 这轮纠偏是有效的，尤其是把 B0.6 中混在一起的 stopping、QoS 口径和 granularity 拆开后，`H=96` 的 `−12.31 bit` 并不是一个轻微数值波动，而是很强的机制信号。代码中旧的 `λ_M`/`μ` 翻倍语义错误也已经避开，G1 的 posterior dual risk

# [ R_\lambda(\Omega)

\min{\lambda_M p,\lambda_F(1-p)}
]

及

# [ Q_\lambda^{(1)}(a)

c_a+\mathbb E[R_\lambda(\Omega')|a]
]

本身是数学自洽的。

但经过代码级审计，我认为现在还不能把结论写成：

> **“formal matched-QoS 下已经证明 adaptive granularity 优于 optimized Direct8。”**

目前更严谨的结论应当是：

> **在一个共享的 QoS-dual one-step stopping framework 下，允许多粒度反馈产生了显著的通信 payload 节省；这一机制已经得到很强的 held-out 证据，但最终的 constrained-policy superiority 还差一个关键公平性闭环。**

最重要的是下面两个问题，其中第一个属于 **P0**。

------

# 1. P0：当前 “common-stop” 实际上并不 action-set neutral

G1 当前的逻辑是：

[
S_{\rm common}:
\quad
\min_{a\in\mathcal A_{\rm FG}}
Q_\lambda^{(1)}(a)<R_\lambda
\Rightarrow \text{CONTINUE},
]

其中

# [ \mathcal A_{\rm FG}

{(i,1),(i,2),(i,4),(i,8)}.
]

代码确实先遍历全部 FG actions 得到 `best_q`，决定是否继续；然后进入 D8 branch 后，再限制到 `(i,8)` 选择实际动作。

因此可能存在状态

[
\boxed{
\min_{a\in\mathcal A_{\rm FG}}Q(a)
<
R_\lambda
\le
\min_{a\in\mathcal A_{\rm D8}}Q(a)
}
]

也就是说：

- 1/2/4-bit 小包值得买；
- 所以公共控制器说“继续”；
- 但所有 8-bit 包都已经不值得买；
- D8 仍被迫执行一个 8-bit action。

这不是代码 bug，而是**比较实验设计上的 action-set leakage**。

它会天然把 D8 成本向上推。

### 为什么这个问题重要

真正“与 granularity 无关的 common stop”不能通过：

[
\min_{a\in A_{\rm FG}}Q(a)
]

定义，因为 **(A_{\rm FG}) 本身就包含 granularity 信息**。

所以报告里“STOP 判定与包粒度无关，因为两者共用 A_all”这个表述需要修改。G0/G1 的确共用**同一个函数**，但这个函数并不是 **granularity-neutral**。G0 报告明确采用了这一结构。

# 2. 不过，我并不认为这会轻易推翻你的结果

H=96：

[

\qquad
E[N_{\rm tx}^{D8}]=1.9583.
]

二者实际上只差：

[
0.0775 \text{ transactions}.
]

而 payload 是：

[
4.5967
\quad \text{vs}\quad
15.6667.

总 bit 差：

[
-12.31,
]

其中报告已经分解为：

[
-1.24;\text{setup}
\quad+\quad
-11.07;\text{payload}.

更直观一点：

FG 每次 transaction 平均 payload 约为

[
\frac{4.5967}{1.8808}\approx2.44\text{ bit},

而 Direct8 是

[
\frac{15.6667}{1.9583}=8\text{ bit}.

所以现在的优势**绝大多数并不是“逼 D8 多发了几次”造成的，而是真正来自 packetization 粒度**。

这也是为什么我认为这条主线值得继续，而不是退回 lower-bound 路线。

# 5. 还有一个 P0/P1：不能把旧 B0.4a-r CPI 原封不动塞回 G2

[
Q_c^{\pi_b}
<
Q_{a_b}^{\pi_b}

在**当时那个 matched base 和当时那个 risk objective** 下成立。代码本身明确强调所有 Q 必须使用 matched base oracle。

而 B0.6-pre 的 N=8 CPI 路线仍然使用：

[
\mu_M=256,\qquad
\mu_F=256e^1,

以及旧 SNR base。

现在 G1 已经变成：

[
\eta_\star=1.2,
\qquad
\lambda_M=512,
\qquad
\lambda_F=512e^{1.2},
]

并且 stopping policy 也完全变化。

因此：

[
\boxed{
\text{旧 CPI certificate}
\not\Rightarrow
\text{新 G1 dual objective 下的 policy improvement}.
}
]

如果直接插回来，它最多叫：

> frozen heuristic CPI override

不能再叫：

> certified policy improvement.

所以我不建议当前 README 所说的“直接把 B0.4a-r frozen CPI override 加回 G2”。

# 8. 这里反而可以补一个非常漂亮的基本定理

因为：

[
A_{\rm D8}
\subset
A_{\rm FG},
]

只要：

- stopping action 相同；
- QoS 定义相同；
- budget/cost accounting 相同；
- FG 可以精确模拟 D8；

那么 policy class 有：

[
\Pi_{\rm D8}
\subseteq
\Pi_{\rm FG}.
]

于是自然得到：

[
\boxed{
J_{\rm FG}^{\star}
\le
J_{\rm D8}^{\star}.
}
]

这个结果本身不是很深，但它是一个**必须满足的数理 sanity theorem**。

真正有价值的是研究**什么时候严格小于**：

[
J_{\rm FG}^{\star}
<
J_{\rm D8}^{\star}.
]

例如存在正占用概率的 reachable state ((x,h))，使：

[
\min_{a\in A_{\rm FG}\setminus A_{\rm D8}}
Q^\star(a|x,h)
<
\min
\left{
R_\lambda(x),
\min_{a\in A_{\rm D8}}Q^\star(a|x,h)
\right}.
]

那么至少局部上存在一个 D8 无法模拟的严格改善 action。

再结合你 B0.4b 的

# [ g_x(b)

E[\min{Y_x,b}]
]

和状态相关

[
b_x^\star,
]

就可以形成比“我们跑实验发现省 bit”强得多的理论链：

[
\boxed{
\text{policy-class dominance}
\rightarrow
\text{state-dependent strictness condition}
\rightarrow
\text{packetization phase transition}
\rightarrow
\text{held-out QoS gain}.
}
]

这才比较像 TSP/TWC 的理论主轴。

# 9. `λ_M=512` 固定意味着当前并不是真正“双参数 calibration”

G1 文档写的是“双参数只在 calibration 上确定”，但实际上代码：

- 固定 `LAM_M=512`；
- 只扫

[
\eta=\log(\lambda_F/\lambda_M).
]

因此实际上只是：

[
\boxed{
\text{fixed dual scale + calibrated dual ratio}.
}
]

而不是完整：

[
(\lambda_M,\lambda_F)
]

双参数校准。

这是因为令

[
\lambda_M=\rho,\qquad
\lambda_F=\rho e^\eta,
]

则：

- (\eta) 主要控制 FA/MD 相对价格和最终 decision boundary；
- (\rho) 控制**错误风险相对于通信 bit 成本的整体权重**。

特别是：

[
Q=c_a+\rho E[\tilde R(\cdot)]
]

中改变 (\rho)，会直接改变 STOP/CONTINUE。

所以 (\rho) 对通信量非常重要。

### 建议

G1r 或 G2 使用：

[
\rho\in
{128,256,512,1024,\ldots},
]

[
\eta\in
{0.8,1.0,1.2,\ldots}.
]

但要：

> grid 预先冻结，只在 calibration 使用，test 不碰。

也可以做 dual ascent，不过第一篇论文我反而建议用小型二维 held-out calibration，更透明、更容易审稿。

# 10. 统计部分总体不错，但有一个表述要修

`mean_ci()` 使用的是：

```python
t.ppf(1-alpha)
```

即 (t_{0.95})。

所以你得到的上端点本质是：

[
\boxed{\text{one-sided 95% t-UCB}}
]

而不是通常意义上的双侧 95% CI。

当前把

[
[L,U]
]

叫“95% CI”不严谨。

不过这一点**不会推翻 H=96 结果**。

甚至因为：

[
B\in[0,H],
]

所以：

[
D=B^{FG}-B^{D8}
\in[-H,H].
]

完全可以不用 t assumption，直接采用 fixed-N Hoeffding：

# [ U_{1-\delta}

\bar D
+
2H
\sqrt{
\frac{\log(1/\delta)}{2n}
}.
]

H=96、(n=1200) 时，即使使用非常保守的 distribution-free bound，`−12.31` 的 margin 仍然很大。

所以我建议 G2 正式版直接换成：

> **paired bounded one-sided concentration bound**

这样“formal certification”更漂亮。

QoS 则可以保留 Wilson，或者更严格用 one-sided Clopper–Pearson。

另外，不需要机械地对 FA/MD/bit 做 Bonferroni：你的最终 Gate 本质是一个 **intersection-union test**——只有所有必要条件同时成立才宣告 PASS；只要每一个 component test 自身按预设 level 控制，就可以构造整体单侧 Gate。论文里最好明确说明这一逻辑，而不是简单声称“多个 95% CI”。

# 12. “同一 UAV selection” 的说法也不准确

FG 实际优化：

[
(i,r)
]

联合动作。

D8 优化：

[
(i,8).
]

因此虽然二者使用相同形式的 one-step Q score，但最优 UAV (i) 完全可能不同。

所以不能说：

> “same UAV selection, only granularity differs.”

更准确是：

> **same selection principle / same score, different admissible feedback actions.**

如果想把 granularity 因果拆得特别干净，可以增加一个极有价值的小消融：

1. D8 先确定 (i^\star)；
2. 两方法都固定同一个 (i^\star)；
3. D8 只能发 8；
4. FG 在该 UAV 上选 1/2/4/8。

得到：

[
\Delta B_{\rm precision-only}.
]

再允许 FG 自己选 UAV：

[
\Delta B_{\rm precision+reselection}.
]

于是可以把收益分成：

[
\boxed{
\text{precision adaptation}
+
\text{granularity-induced sensor reselection}
+
\text{adaptive stopping}.
}
]

这个 decomposition 很有论文味道。

# 13. 通信与感知物理层面：当前 B0.7 可以作为机制模型，但还不是完整通信结论

当前 `SparsePlanner` 的基本成本还是：

[
c_a=b_h+(r'-r),
]

并明确对应理想 radio reporting abstraction。

本地 detector 则是规范的 Gaussian LLR abstraction：

[
L_i|H_0
\sim
\mathcal N(-a_i^2/2,a_i^2),
]

[
L_i|H_1
\sim
\mathcal N(+a_i^2/2,a_i^2).
]

nested quantizer 和 message-LLR 构造也是正确的，尤其是 nested partition 与 message PMF 从 H0/H1 精确积分获得。

所以**作为统计检测层的 MVS 是合理的**。

但若最终投稿面向 TWC/ISAC，需要至少补一个 robustness section：

[
p_{{\rm succ},i}<1
]

时，例如 ARQ：

[
E[C_{i,r}]
\approx
\frac{b_{\rm setup}+\Delta r}
{p_{{\rm succ},i}},
]

或者显式 packet-erasure/CRC/retransmission。

否则论文最好明确说：

> 本文研究 post-detection evidence reporting 层，不声称联合优化 waveform/channel coding。

这是符合通信基本原则的。

2024/2025 的 FE-SRTS 已经同时涉及反馈、量化以及 fading 下的 distributed detection，所以不能把“feedback + quantization + early stop”本身包装成新贡献。([J-GLOBAL](https://jglobal.jst.go.jp/detail?JGLOBAL_ID=202502228694531230&utm_source=chatgpt.com))

而 2026 已经出现专门针对 ISAC 的 adaptive quantization 工作，将 quantization noise 和 detection probability 显式关联，因此“ISAC 中自适应量化”单独也已经不够新。([EurekaMag](https://eurekamag.com/research/103/465/103465689.php?utm_source=chatgpt.com))

# 14. 你现在真正应该锁定的创新点

我建议不要再叫得过宽。

当前最有希望的创新组合是：

[
\boxed{
\textbf{QoS-Constrained Feedback-Granularity-Aware Sequential Evidence Acquisition}
}
]

核心不是：

- sequential detection；
- optimal stopping；
- sensor selection；
- quantization；
- adaptive quantization；
- feedback；
- UAV cooperative sensing；

这些都已有大量先例。online sensor selection + stopping 本身早已有严格理论；quantized sequential message exchange 也已有专门研究。([Experts@Minnesota](https://experts.umn.edu/en/publications/sequential-hypothesis-test-with-online-usage-constrained-sensor-s-2/?utm_source=chatgpt.com))

真正可守的是三层组合：

**第一，反馈粒度是状态相关的决策变量，而不是静态量化率。**

[
a_t=(i,r_i\rightarrow r_i').
]

第二，第一包的实际 realization 决定是否值得继续 refinement。

第三，在 transaction setup cost 下，有你已经建立的局部 phase-transition：

[
g_x(b)=E[\min(Y_x,b)]
]

及

[
b_x^\star.
]

这和 2026 大量 UAV-ISAC 工作主要做 beamforming、trajectory、bandwidth/resource allocation 的方向明显不同。当前文献仍主要围绕 sensing/communication physical resource competition，例如 UAV 协同检测中的能量、波束和轨迹优化，以及 multistatic sensing resource allocation。([数字对象标识符](https://doi.org/10.1109/tvt.2026.3685205?utm_source=chatgpt.com))

你的差异化应该放在：

> **检测统计量产生之后，如何以反馈控制的可变证据粒度逐步获取信息。**

这是更干净的研究位置。
