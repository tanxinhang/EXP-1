### 一、先纠正 B0.6 的最终结论

报告中：

- H=48：Direct8 (P_{FA}=0.1133)
- H=96：Direct8 (P_{FA}=0.1400)
- QoS 要求：(P_{FA}\le0.12)

H=96 的 Direct8 **点估计已经直接违规**；H=48 虽然点估计略低于 0.12，但按与你 CR 完全相同的 Wilson 95% 上界计算，其 U95 约为 **0.141**，也不能认证满足 0.12。POTS 的 (P_{FA}=0.2483) 更明显不满足。

所以目前严格能够说的是：

[
\boxed{
\text{在共同 }\eta_{\rm nat}=1\text{ 工作点下，CR 用更多 bit，换来了更好的检测性能。}
}
]

还不能说：

[
\boxed{
\text{在相同 QoS 下 Direct8 比 CR 更省 bit。}
}
]

因为目前 Direct8 并未证明属于可行集。

这与之前 G5 曾经出现过的 “unmatched comparison 被误称 matched” 本质上是同一个问题，只是这次更隐蔽。

因此我建议把当前 B0.6 的 `bit FAIL` 暂时降级为：

> **COMMON-THRESHOLD BIT LOSS / MATCHED-QoS UNRESOLVED**

而不是论文生死意义上的最终 FAIL。

## 二、当前还有第二个理论口径需要修正

当前 regime map 写的是：

> “理论预测的 crossover 未出现”。

这个表述也过强。

B0.4b 真正证明的是**固定状态 (x)、固定 UAV/反馈动作对**上的局部关系：

# [ g_x(b)

# Q_{\rm prog}(x;b)-Q_{\rm dir}(x;b)

\mathbb E[\min(Y_x,b)],
]

以及状态相关的

[
b^\star(x).
]

它证明的是：

[
b<b^\star(x)
\quad\Longrightarrow\quad
\text{这个状态上的 progressive/direct 局部偏好}
]

发生改变。

它**没有证明**

# [ D(b)

\mathbb E[B^{CR}-B^{D8}]
]

一定单调，更没有证明整个 episode 级 CR policy 与完全不同停止规则的 D8 policy 必须在 (b^\star(x_0)\approx7) 附近发生全局 crossover。

因为全局量还混入了：

[
\text{state occupancy}
+
\text{stopping time}
+
\text{UAV selection}
+
\text{remaining budget}
+
\text{CPI override}.
]

因此 regime map 应改成：

> **system-level regime diagnostic: no global crossover observed**

不要叫：

> theory-predicted crossover failed.

这样 B0.4b 理论本身并没有受到 B0.6 map 的反证。

# 三、真正的根因也应该再提高一层：不是单纯 `eta_b=2`

你目前定位：

[
\eta_b^{CR}=2
\quad\text{vs}\quad
\eta_{\rm nat}^{D8}=1
]

这个判断是对的，但它还是“症状”。

代码确实明确这么写：

```python
SNRDirectBase(... eta_b=2.0)
```

而 Direct8 是：

```python
if abs(lam) >= ETA_NAT: stop
```

更深层的问题其实是：

[
\boxed{
\text{停止策略没有和最终的通信约束优化目标统一。}
}
]

特别是现在

# [ \eta_{\rm nat}

\log\frac{\mu_F}{\mu_M}
=1,
]

意味着最终判决边界在 (\Omega=1)。

但两个 acquisition policy 都在用：

[
|\Omega|\ge\kappa
]

这种**围绕 0 对称的 stopping rule**。

当 (\mu_F\neq\mu_M)、判决边界本身不在 0 时，这种对称停止规则并没有天然的 Bayes-optimal 理由。更合理的是 posterior-risk / cost-to-go stopping，或者至少是两个不同的停止边界：

[
A(h)<\eta_{\rm dec}<B(h).
]

顺序检测与受使用约束的传感器选择文献本来就把“何时停止”和“选择哪个传感器”联合写成带采样成本的 Bayesian optimal stopping；所以**optimal stopping 本身不能作为你的创新点**。([Experts@Minnesota](https://experts.umn.edu/en/publications/sequential-hypothesis-test-with-online-usage-constrained-sensor-s-2?utm_source=chatgpt.com))

我最推荐这条路线。

# 五、B0.6-r 应该非常小，不要碰 CPI

第一步，把所有方法都算：

[
U_{95}(P_{FA}^{m}),
\qquad
U_{95}(P_{MD}^{m}),
\qquad
m\in
{CR,D8,POTS}.
]

每种方法先分类：

[
m\in
{\text{FEASIBLE},
\text{INFEASIBLE},
\text{UNCERTAIN}}.
]

只有两个算法都 FEASIBLE 时，才允许比较：

[
E[B^A]-E[B^B].
]

也就是说 Gate 逻辑应改为：

[
\boxed{
A\prec B
\iff
A,B\in\mathcal F_{\rm QoS}
\quad\land\quad
U_{95}(E[B^A-B^B])<0
}
]

如果 Direct8 不满足 QoS：

不能输出：

> CR bit FAIL.

只能输出：

> Direct8 has lower raw communication cost but is not certified QoS-feasible at this operating point.

这一步完全不属于“调参把 CR 调赢”，只是**修公平性定义**。

# 七、如果继续优化，不建议直接把 `eta_b=2 -> 1`

这是最容易做的事情，但不建议作为正式算法。

因为 reviewer 会非常自然地问：

> “B0.6 输了以后，你看到 Direct8 用 1，于是把 CR 也改成 1，这是不是 post-hoc tuning？”

很难解释。

更好的做法是把研究问题重新形式化。

真正要解的是：

[
\boxed{
\min_\pi
\mathbb E_\pi[B]
}
]

subject to

[
P_{FA}^{\pi}\le\alpha,
\qquad
P_{MD}^{\pi}\le\beta.
]

建立两个 QoS 对偶价格：

[
\lambda_F\ge0,
\qquad
\lambda_M\ge0,
]

则 Lagrangian 可以写成：

# [ \mathcal L(\pi,\lambda_F,\lambda_M)

\mathbb E_\pi[B]
+
\lambda_F(P_{FA}^{\pi}-\alpha)
+
\lambda_M(P_{MD}^{\pi}-\beta).
]

这就把“通信 bit”和“检测错误”统一到了同一目标，而不是一个模块优化 Bayes risk、另一个模块再用 QoS Gate 检查。

# 八、对应的 stopping rule 会非常自然

设当前 posterior：

[
p_x=P(H_1|x).
]

如果现在停止，最小 terminal dual risk 为：

# [ \boxed{ R_\lambda(x)

\min
{
\lambda_M p_x,;
\lambda_F(1-p_x)
}.
}
]

其中：

- 判 (H_0)：承担 miss 风险 (\lambda_Mp_x)；
- 判 (H_1)：承担 false-alarm 风险 (\lambda_F(1-p_x))。

如果继续采 action (a=(i,r))，代价：

# [ Q_\lambda(a|x,h)

c_a+
\mathbb E[
V_\lambda(X',h-c_a)
|x,a
].
]

因此真正统一的 Bellman 结构就是：

# [ \boxed{ V_\lambda(x,h)

\min
\left{
R_\lambda(x),
;
\min_{a\in\mathcal A_h(x)}
\left[
c_a+\mathbb E V_\lambda(X',h-c_a)
\right]
\right}.
}
]

这才同时回答：

1. 要不要继续？
2. 如果继续，找哪个 UAV？
3. 发多少 bit？
4. progressive 还是 direct？

而不是预先人为规定：

[
|\Omega|\ge1
\quad\text{或}\quad
|\Omega|\ge2.
]

# 九、但部署版本不用做完整 DP

这里不要重新陷入 full exact planner。

可以用 one-step approximation：

# [ Q_\lambda^{(1)}(a|x,h)

c_a+
E[R_\lambda(X')|x,a].
]

于是：

[
\boxed{
\text{STOP}
\iff
R_\lambda(x)
\le
\min_a Q_\lambda^{(1)}(a|x,h).
}
]

这其实仍然是 conditional VoI 类型，但和你以前 VoIBase 有一个重要区别：

以前：

[
\mu_M,\mu_F
]

是固定 Bayes cost。

现在：

[
\lambda_M,\lambda_F
]

是针对：

[
P_{FA}\le\alpha,\quad
P_{MD}\le\beta
]

从 calibration set / dual problem 中求出来的。

所以我会把它叫：

> **QoS-dual-calibrated stopping**

而不是新的 VoI。

近期通信受限的分布式风险控制工作也把可靠性约束与通信开销统一并动态调整阈值，这说明“可靠性约束下动态阈值”本身也不是足够的新颖点；你的创新仍然应该落在 feedback granularity 的状态相变及其与停止控制的耦合上。([Aalborg Universitets forskningsportal](https://vbn.aau.dk/en/publications/conformal-distributed-remote-inference-in-sensor-networks-under-r/?utm_source=chatgpt.com))

# 十、最关键的新实验：把 STOP 和 GRANULARITY 拆开

这是我认为下一阶段最值得做的实验。

使用**完全相同的 outer stopping controller**：

[
S_\lambda(x,h).
]

如果 STOP：

两种方法都 STOP。

如果 CONTINUE：

### Direct8

限制 action space 为：

# [ \mathcal A_{\rm D8}

{(i,8)}.
]

### Proposed

允许：

# [ \mathcal A_{\rm FG}

{(i,1),(i,2),(i,4),(i,8)}.
]

这时：

[
\boxed{
\text{两者唯一差别就是 feedback granularity。}
}
]

这比当前 CR vs Direct8 干净太多。

当前对比同时变了：

- stopping threshold；
- candidate policy；
- granularity；
- CPI override；
- transaction count。

因此即使输赢，也无法完全归因于多粒度机制。

新的 common-stop Gate 可以真正回答：

> **在相同停止逻辑、相同检测目标下，仅允许 adaptive packetization 是否可以降低 communication bits？**

这才是 B0.4b 理论最应该支撑的实验。

# 十一、B0.4b 可以在这里发挥真正作用

不要再用 (b^\star(x)) 去预测全局 CR-vs-D8 crossover。

应该把它用于**局部 action pruning**。

例如同一个 UAV、同一个状态，如果 theorem 已经证明：

[
b<b^\star(x,i),
]

则 progressive candidate 有理论优势；

反之在 Case C 且：

[
b>b^\star(x,i),
]

direct candidate 局部占优。

这样可以构造：

[
\mathcal A_{\rm phase}(x,h)
\subset
\mathcal A(x,h),
]

先用解析 phase theorem 去掉被局部支配的 packetization action，再让 CPI 在剩余动作中做 certified comparison。

这会形成一个很漂亮的三层结构：

[
\boxed{
\text{QoS-calibrated STOP}
\rightarrow
\text{phase-theorem granularity pruning}
\rightarrow
\text{paired-difference CPI}
}
]

这样 B0.4、B0.4a、B0.4b 才真正串成一条算法链，而不是三个相对独立的模块。

# 十二、我建议把新分支定成 B0.7，而不是继续改 B0.6

因为 B0.6 是冻结后的 negative test，必须保留。

不要覆盖它。

新开：

> **B0.7 — QoS-Calibrated Feedback-Granularity-Aware Evidence Acquisition**

但创新措辞建议保守：

不是：

> “我们首次联合优化 stopping 和 quantization。”

这类东西早已有 sequential sensing / adaptive quantization 工作。受约束的 sequential sensor selection 已经明确研究“最小 expected samples subject to error probabilities”并转化为 Bayesian optimal stopping。([Experts@Minnesota](https://experts.umn.edu/en/publications/sequential-hypothesis-test-with-online-usage-constrained-sensor-s-2?utm_source=chatgpt.com))

你真正有辨识度的是：

[
\boxed{
\text{state-dependent packetization phase transition}
+
\text{QoS-calibrated stopping}
+
\text{paired certified acquisition}
}
]

特别是 per-transaction setup cost 下：

# [ g'_x(b)

P(\text{additional transaction})
]

这一层仍然是很好的理论核心。
