\text{1-bit evidence 疑似加了两遍}

\boxed{
\text{首轮 header + 1bit 成本也加了两遍}
}

所以 B0 报告中 `1bit-POTS` “无法达到 matched QoS”的结论目前不能使用。代码位置非常明确。

# 四、B0 最值得重写的是 Header Proposition

当前报告使用：

[
b_h>0
\Longrightarrow
\text{cross-level actions 重新具有物理价值}.
]

这个说法作为实验描述可以，但作为数学 Proposition **过强**。

严格的结论应该是：

[
\boxed{
b_h=0
\Rightarrow
\text{adjacent refinement weakly dominates direct jump}
}
]

而：

[
\boxed{
b_h>0
\Rightarrow
\text{这种 universal dominance 被打破}
}
]

不是：

[
b_h>0
\Rightarrow
\text{任何状态下 direct jump 都有价值}.
]

# 五、可以把这个理论进一步拔高成一个真正漂亮的定理

考虑：

[
r\rightarrow r'\rightarrow r'',
]

定义：

[
\Delta_1=r'-r,
\qquad
\Delta_2=r''-r'.
]

直接跨级：

# [ Q_{\rm dir}

b_h+\Delta_1+\Delta_2
+
E[R(x'')].
]

渐进方式先发送 (r')，观察实际 coarse message (m')，然后再决定停止还是继续：

# [ Q_{\rm prog}

b_h+\Delta_1
+
E_{m'}
\left[
\min
\left{
R(x'),
b_h+\Delta_2+
E[R(x'')|x']
\right}
\right].
]

定义 fine evidence 在 coarse state 上的条件决策价值：

# [ D(x')

## R(x')

E[R(x'')|x'].
]

那么可以直接得到：

# [ \boxed{ Q_{\rm prog}-Q_{\rm dir}

E_{x'}
\left[
\min
\left{
D(x')-\Delta_2,;
b_h
\right}
\right].
}
]

这比目前简单的 (q<7/23) 强很多。

当：

[
b_h=0,
]

有：

# [ Q_{\rm prog}-Q_{\rm dir}

E[\min{D-\Delta_2,0}]
\le0.
]

所以自动得到：

[
\boxed{
\text{zero setup cost}
\Rightarrow
\text{progressive weakly dominates direct}.
}
]

而当：

[
b_h>0,
]

符号由：

[
D(x')
]

的状态分布决定。

于是就出现真正的：

[
\boxed{
\text{state-dependent feedback-granularity phase transition}.
}
]

这就是我认为目前最值得拔高的理论点。

# 八、通信物理上还有一个当前没有计入的开销

当前动作：

[
a=(i,r\rightarrow r')
]

实际上意味着 fusion UAV 必须告诉网络：

> “UAV (i)，请把证据提升到 (r') bit。”

这是一个 **feedback/grant/query transaction**。

但当前成本：

[
c_a=b_h+(r'-r)
]

主要只体现 evidence packet 本身。

如果你的算法每获得一个 coarse message 就重新决策一次，那么 progressive policy 会产生更多：

[
\text{request/grant/ACK/feedback opportunities}.
]

如果这些开销完全免费，渐进策略会被系统性高估。

因此 B0.1 最好把：

[
b_h
]

重新解释成：

# [ \boxed{ b_{\rm setup}

b_{\rm data-header}
+
b_{\rm control}
+
b_{\rm feedback}
}
]

或者更物理一点：

# [ c_a^{time}

T_{\rm grant}
+
T_{\rm PHY/MAC}
+
\frac{r'-r}{R_i}
+
T_{\rm ACK}.
]

这样你的 `cross-level` 就不只是“量化 bit level”。

它变成：

[
\boxed{
\text{adaptive packetization / feedback granularity}.
}
]

这个研究定位明显更强。

# 九、我不建议下一步直接上普通 MCTS 或 sampled lookahead

B0 已经非常清楚地暴露了计算复杂度：

[
H=40:\sim1.8\times10^4,
]

到：

[
H=48:\sim2.17\times10^6,
]

随后迅速不可行。

这个现象不是坏结果，它实际上给你提供了第二个非常好的论文理论点：

[
\boxed{
\text{exact reachable-cone explosion}.
}
]

下一步我更建议做：

[
\boxed{
\text{Certified Rollout RBL / PAC-RBL}
}
]

而不是普通 Monte-Carlo tree search。

核心是选择一个可靠 base policy：

[
\pi_0
]

例如 Adaptive Direct-8 或 H=40 exact policy，然后：

# [ Q_a^{\pi_0}(x)

c_a+
E[J^{\pi_0}(x')].
]

用 rollout 估计：

[
\hat Q_a.
]

如果单次 return 有界：

[
0\le G\le C_{\max},
]

Hoeffding 给出：

[
P(
|\hat Q_a-Q_a|>\varepsilon
)
\le
2\exp
\left(
-\frac{2M\varepsilon^2}{C_{\max}^2}
\right).
]

因此：

[
\boxed{
M\ge
\frac{C_{\max}^2}{2\varepsilon^2}
\log\frac{2|\mathcal A|}{\delta}
}
]

即可给 action evaluation 一个显式的 ((\varepsilon,\delta)) 保证。

实际实现可以进一步换成 empirical-Bernstein confidence interval，动态停止采样。

这样论文不是：

> “Exact 太慢，所以我们用了 Monte Carlo”。

而是：

> **“Exact oracle 揭示了 state-cone explosion；因此提出 confidence-certified adaptive rollout，在给定错误概率下只采样决策边界附近的动作。”**

这个档次完全不一样。

# 十、B1 的方向也建议改一下：不要把“加入 Rician”当创新

已有 successive-refinement hypothesis testing 理论至少可以追溯到 IEEE TIT 2008，因此“coarse-to-fine evidence”本身不是新点。([ResearchGate](https://www.researchgate.net/publication/3087045_Successive_Refinement_for_Hypothesis_Testing_and_Lossless_One-Helper_Problem?utm_source=chatgpt.com))

更关键的是，FE-SRTS 已经把 **ordered distributed detection、feedback、quantized LLR、fading、retransmission、power control 和实际协议 overhead** 放到一个系统里了。也就是说，仅仅增加 fading/ARQ/feedback 不能成为 O-PEF 的核心创新。([ResearchGate](https://www.researchgate.net/publication/387009984_Energy-Efficient_Distributed_Detection_Through_Feedback-Assisted_Ordered_Transmissions_in_the_Presence_of_Fading_and_Quantization?utm_source=chatgpt.com))

2025 年关于 heterogeneous-cost active sequential hypothesis testing 的工作也特别提醒：简单逐动作的“information/cost bit-per-buck”未必正确，更合理的是直接围绕**总期望代价和最终错误约束**设计策略。这恰好支持你现在 CMDP/RBL 的路线，而不是退回边际收益比 greedy。([arXiv](https://arxiv.org/abs/2509.11632?utm_source=chatgpt.com))

所以 B1 应该研究：

[
\boxed{
\text{packet-length-dependent reliability}
+
\text{feedback granularity}
}
]

而不是泛泛的：

[
\text{Rician fading}.
]

例如：

# [ p^{succ}_{i,a}

f(\gamma_i^c,b_h+r'-r),
]

那么大 packet：

[
0\to8
]

虽然少一次 header，却可能具有更高 PER；小 packet progressive 虽然多 setup，但单包可靠性更高。

这时：

[
\boxed{
\text{precision choice}
\leftrightarrow
\text{packetization}
\leftrightarrow
\text{PER}
\leftrightarrow
\text{feedback opportunity}
}
]

才真正形成通信与检测的耦合。

# 十一、ARQ 这里其实还能再得到一个定理

你 SystemModel 里的 B1 当前使用：

[
\bar c_a=\frac{c_a}{p_i^{succ}}.
]

这个不是纯 heuristic。

如果满足：

[
\text{i.i.d. attempts},
]

失败不泄露 sensing information，

[
p_i^{succ}
]

在 retry 中不变化，而且没有 deadline/channel memory，那么 explicit self-loop Bellman：

# [ V

\min
\left{
R,
c+
pV(x^+)+(1-p)V(x)
\right}
]

继续动作部分整理后得到：

# [ V

\frac{c}{p}
+
V(x^+).
]

因此：

[
\boxed{
\text{explicit retry MDP}
\equiv
\text{collapsed action with cost }c/p
}
]

在这些假设下是可以正式证明的。

这意味着原来计划的 MVS-B2：

> “explicit packet loss”

很可能**不应该成为一个新算法阶段**。

它应该降级成：

[
\boxed{\text{abstraction-equivalence theorem + verification Gate}}
]

只有当：

[
p^{succ}=p^{succ}(L,\gamma,t),
]

或者存在 deadline/channel memory 时，explicit failure state 才真正创造新的控制问题。

# 十二、感知模型不要急着完整 OTFS 化，但必须加一座“物理桥”

目前 Gaussian detector：

[
L_i|H_0
\sim
\mathcal N(-a_i^2/2,a_i^2),
]

[
L_i|H_1
\sim
\mathcal N(+a_i^2/2,a_i^2)
]

本身数学非常干净。

而且它有一个非常漂亮的解释：

# [ D_{\rm KL} (P_1\Vert P_0)

\frac{a_i^2}{2}.
]

所以：

# [ \boxed{ a_i^2

2D_{\rm KL}(P_{1,i}\Vert P_{0,i}).
}
]

这给了你一个非常自然的 ISAC bridge：

[
\text{OTFS/OFDM echo}
\rightarrow
T_i
\rightarrow
p(T_i|H_h,\xi_i)
\rightarrow
D_{\rm KL}
\rightarrow
a_i^2
]

或者更一般直接得到：

[
P(M_i^{(r)}=m|H_h,\xi_i).
]

这样 O-PEF 主算法实际上并不依赖 Gaussian：

[
\boxed{
\text{它只依赖 calibrated message channel PMFs}.
}
]

这反而应该提升成一个模型层面的结论：

> **O-PEF is detector- and waveform-agnostic once the local evidence channel is calibrated.**

比强行把 OTFS 参数塞进 Bellman 方程更加干净。

# 十三、真正值得作为第二条创新线的是 calibration robustness

SystemModel 已经认识到 calibration mismatch 问题，但代码还没有把它变成正式 Gate。

这是一个比“再换个 fading model”更有研究价值的方向，因为 task-oriented communication 的近期工作也越来越强调 distribution shift 对任务层编码/传输的破坏。([arXiv](https://arxiv.org/abs/2405.09514?utm_source=chatgpt.com))

未来可以定义：

[
P_{i,h}^{(r)}
\in
\mathcal U_{i,h}^{(r)}
]

例如 KL-ball：

[
D_{\rm KL}(Q\Vert \hat P)
\le\rho.
]

把 Bellman expectation：

[
E_P[V(x')]
]

替换成：

[
\sup_{P\in\mathcal U}
E_P[V(x')].
]

那么就得到：

[
\boxed{
\text{Distributionally Robust O-PEF}
}
]

不过我建议这是 **第二阶段创新**，不要现在和 scalable planner 一起做，否则又会发散。

# 十四、软件层还需要一次真正的“论文级封板”

当前 `smoke_test.py` 基本还是 print-based smoke test，没有形成真正的 regression test suite。

此外我还看到两个值得修的小问题。

`GaussianDetectorModel(prior=...)` 保存了 prior，但 `sample_hypotheses()` 实际始终用：

[
H\sim\operatorname{Bernoulli}(0.5),
]

因此非 0.5 prior API 当前是不一致的。

另一个是 SparsePlanner：

```python
key = (int(x_int), int(h))
```

而 `b_h` 和未来：

[
c_a/p_i^{succ}
]

都可能是浮点数。当前 (b_h=16) 没问题，但到了 B1，若 horizon/resource cost 变成非整数，这个 `int(h)` 会导致 memo key collision 或预算失真。

因此 B1 之前必须确定：

[
\boxed{
\text{resource lattice}
}
]

例如统一使用：

[
\Delta c=0.1
]

并把所有 cost integerize 成：

# [ \tilde c

\operatorname{round}(c/\Delta c),
]

同时给出离散化误差界，而不是直接让 float budget 混进现有整数 RBL。

}
]

其中 B0.1 先修 POTS、best-parameter reporting、CRN、Monte-Carlo sample size、置信区间、自然决策/NP 口径、Top-K 全扫以及 regression tests。

B0.2 加 **Adaptive Direct-8 optimal baseline**，把目前 `b_h>0` 命题升级为我上面给出的 state-dependent conditional-VoI theorem，同时把 `q<7/23` 降为 communication-only corollary，并把 feedback/control setup 真正计入成本。

B0.3 才是现在最有潜力形成“算法创新”的部分：Exact sparse planner 保留为局部 oracle，同时提出 **confidence-certified rollout / sampled RBL**，解决 N=8 深 horizon 的 reachable-cone explosion，而且给 ((\varepsilon,\delta)) 决策质量保证。

之后 B1 再加入 packet-length dependent PER、异构 U2U、positive/independent/anti-correlated sensing-communication regimes。B2 explicit retry 不再单独立项，而是先证明 memoryless ARQ collapse theorem；只有 theorem 条件被破坏时才进入真正的 stochastic communication-state MDP。

# 十六、这样收敛以后，论文的核心故事会明显更强

我会把论文从：

> **“一种多 UAV 渐进式软信息融合方法”**

升级为：

> **“通信 transaction/setup 开销下，面向分布式 ISAC 检测的自适应证据 packetization 与反馈粒度控制。”**

对应数学主线是：

[
\text{nested evidence}
\rightarrow
\text{sufficient evidence state}
\rightarrow
\text{QoS-CMDP}
\rightarrow
\text{header-induced loss of adjacent dominance}
\rightarrow
\text{state-dependent packetization}
\rightarrow
\text{certified scalable rollout}.
]

这里真正有机会形成论文级新意的不是单独的 quantization、feedback、ordered transmission 或 fading——这些已有研究都覆盖了相当多。([ResearchGate](https://www.researchgate.net/publication/3087045_Successive_Refinement_for_Hypothesis_Testing_and_Lossless_One-Helper_Problem?utm_source=chatgpt.com))

而是：

[
\boxed{
\begin{aligned}
&\text{realized-message-dependent UAV selection}\
+&\text{adaptive evidence precision}\
+&\text{adaptive feedback granularity}\
+&\text{per-transaction setup cost}\
+&\text{matched detection QoS}\
+&\text{certified scalable planning}.
\end{aligned}}
]

这个定位既没有违背检测理论，也没有把通信层抽象得不切实际，而且比继续往系统里堆模块更容易形成一个**收敛、可证明、可投稿**的故事。

**因此我现在不建议继续实现 MVS-B1。** 下一轮最值得直接做的是 **B0.1**：先把我发现的 `1bit-POTS`、500-vs-50k、NP/Bayes 口径、(q) Gate、best-param reporting 和测试体系一次性修掉，再重新跑 B0。只有这次 Gate 干净之后，才值得进入 Certified Scalable Planner。
