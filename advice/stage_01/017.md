可以继续做 **B0.7-G2**。这次审计后，我认为 **G1r 已经把阻止 G2 的 P0 闭掉了**：保守的 (A_{\rm D8})-reference stopping 下，H=96 仍然双方 QoS-feasible，且 distribution-free Hoeffding U95 仍为负；因此现在继续 G2 是“验证真正公平的 constrained policy comparison”，不是继续调参救结果。

不过建议在 G2 代码里顺手修 3 个小口径，不需要再单独开一轮 G1r。

### 一、G1r 审计后的三个小修正

**P1-1：forced-continuation 的 2.21%/2.77% 要改名。** 当前 `n_dec` 是在 `q_FG<R`、即 `S_common=CONTINUE` 后才累加，因此严格口径是

[
P(F=1\mid S_{\rm common}=\mathrm{CONTINUE}),
]

不是所有 stopping-decision states 上的 (P(F=1))。 这不会削弱结论，因为若把 STOP states 加进分母，比例只会更低。

**P1-2：`ΔB_forced` 不应叫 causal extra cost。** 目前计算的是 F 状态上 D8 实际执行 full packet 的成本之和；如果反事实 STOP，后续轨迹也会变化，因此建议改成 `gross forced-action cost`。H=96：

[
1560/(2\times600)=1.30
]

bit/episode。即使极端地把这 1.30 bit 全视为 leakage bias，也远低于原 G1 的 12.31 bit gap，这其实是非常好的 robustness statement。

**P1-3：dual-Q regression 的状态覆盖需要加强。** `regress_q1()` 是每个 UAV 的 `z∈[0,278]` 均匀抽样，但 8-bit code 本身占 256/279 个编码，所以它天然大量抽到已经达到 r=8 的状态；200 个随机 joint states 最后只检查了 168 个合法动作。 公式正确性现在已经很可信，但 G2 建议增加 root + on-policy reachable + resolution-stratified 三类 regression。这个属于测试覆盖增强，不阻止 G2。

另外，`emulate_d8(..., n_ep_check=50)` 实际循环 `2*n_ep_check=100` 条 episode，但返回/report 写 50，属于纯 P2 计数表述，可以顺手修。

# 二、G2 现在真正应该回答的问题

G1/G1r 回答的是：

\boxed{\text{控制其它因素后，feedback granularity 本身有没有价值？}}

\lambda_F=\rho e^\eta,

\rho\min{p_x,e^\eta(1-p_x)},

# [ Q_{\rho,\eta}^{(1)}(a|x,h)

c_a+
E[R_{\rho,\eta}(X')|x,a].

但动作集分别为

# [ \mathcal A_{\rm FG}

# [ \mathcal A_{\rm D8}

{(i,8):r_i<8}.

# [ a_m^\star

\arg\min_{a\in\mathcal A_m}

[
\Omega>\eta\Rightarrow H_1.

这样就彻底不存在 G1 的 action-set leakage。

# 三、一个非常重要的命名修正：G2 不是求 (J_m^\star)

这一点我建议现在就冻结，避免论文后面再返工。

理论上可以定义：

# [ J_m^\star

\inf_{\pi\in\Pi_m}
E_\pi[B]
]

s.t.

[
P_{\rm FA}^{\pi}\le\alpha,\qquad
P_{\rm MD}^{\pi}\le\beta.
]

但是 G2 并没有对所有策略 (\Pi_m) 求全局最优，而只是搜索一个 **one-step dual controller family** 的有限参数 grid。

因此实验里不要写：

> optimized FG / globally optimized Direct8

更准确是：

[
\boxed{
\text{separately calibrated one-step QoS-dual controllers}.
}
]

可以定义

# [ \Theta

\mathcal R_\rho\times\mathcal R_\eta,
]

# [ \hat\theta_m

\arg\min_{\theta\in\Theta}
\widehat E_{\rm cal}[B_m(\theta)]
]

s.t.

[
U_{\rm cal}(P_{\rm FA}^{m,\theta})\le\alpha,
\qquad
U_{\rm cal}(P_{\rm MD}^{m,\theta})\le\beta.
]

然后 test 的对象是：

[
\pi_{\rm FG}^{\hat\theta_{\rm FG}}
\quad\text{vs}\quad
\pi_{\rm D8}^{\hat\theta_{\rm D8}}.
]

这已经是一个很强而且完全诚实的结论。

# 十、创新定位目前反而更清楚了

我刚又核了一下最近 2025–2026 的工作。当前 UAV/networked-ISAC 的主流仍大量围绕 sensing waveform length、beam allocation、trajectory、power、communication throughput 和 detection/tracking reliability 做资源适配；例如 2026 的 multistatic UAV detection 工作主要优化 sensing transmission rate/beam/resource occupancy，另一类 networked UAV detection 则联合 pilot、功率和 beam direction。([arXiv](https://arxiv.org/abs/2606.21677?utm_source=chatgpt.com))

另一方面，sensor selection + adjustable quantization 已经在其它无线 sensing/estimation 问题中存在，因此“选择节点 + 分配 bit 数”本身不能作为创新。([arXiv](https://arxiv.org/abs/2412.05626?utm_source=chatgpt.com)) Sequential controlled sensing 也早已有成熟理论，因此 stopping/controlled sensing 本身更不能作为主创新。([IEEE Xplore](https://ieeexplore.ieee.org/abstract/document/10423411?utm_source=chatgpt.com))

所以现在这条线应该坚定收敛到：

[
\boxed{
\textbf{realized-evidence-dependent feedback granularity}
}
]

即第一包实际收到的 quantized evidence 改变后续：

[
\text{which UAV}
+
\text{whether refine}
+
\text{how many additional bits}
+
\text{whether stop}.
]

再配上已有的状态相关 phase-transition：

[
g_x(b)=E[\min{Y_x,b}],
\qquad b_x^\star,
]

以及 G1r 的 conservative mechanism certificate。

这个组合比继续叠 planner 模块更有创新性。

## 最终建议

**继续做 B0.7-G2，而且现在正是该做 G2 的时候。**

但我会把 G2 的定位冻结为：

[
\boxed{
\textbf{Separately Calibrated QoS-Dual Policy-Family Certification}
}
]

而不是“再优化一次 FG”。

核心顺序保持：

[
\text{G1r：机制成立}
\rightarrow
\boxed{\text{G2：各自最公平 controller 后仍成立？}}
\rightarrow
\text{G3：DualCPI 是否还有独立增益？}
]

如果 **G2 PASS**，实际上论文的核心 performance 主线已经闭环；这时即使后面的 DualCPI 增益很小，也不应再继续堆复杂算法。G3 应变成一个“**是否值得纳入主算法**”的 Gate，而不是必做的性能增强。

这能避免系统再次从“反馈粒度这一核心科学问题”跑回复杂 planner/sample-complexity 工程。
