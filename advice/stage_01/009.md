# 二、需要修的第一个问题：T17a 现在其实是“真但空”的测试

这是我本轮审计发现最值得修的一处。

当前 T17a：

```python
Q = ...
L = Q - width
U = Q + width

best = int(np.argmin(Q))

if U[best] <= min(L_other) + eps:
    ok &= Q[best] <= min(Q) + eps
```

问题在于：

[
best=\arg\min Q
]

本身就意味着：

# [ Q_{best}

\min_aQ_a
\le
\min_aQ_a+\epsilon.
]

所以**无论 certificate condition 是否正确，最后的 implication 永远成立。**

也就是说现在所谓：

> T17a deterministic certificate implication 2000/2000 PASS

实际上并没有测试 certificate theorem。

### 正确测试方式

应该随机选择一个**不保证是真最优的 candidate** (j)，然后生成同时覆盖真值的区间：

[
L_a\le Q_a\le U_a.
]

只有当：

[
U_j
\le
\min_{b\neq j}L_b+\epsilon
]

时，再断言：

[
\boxed{
Q_j\le\min_bQ_b+\epsilon.
}
]

同时要单独测 STOP：

[
R_{\rm stop}
\le
\min_bL_b+\epsilon
\Rightarrow
R_{\rm stop}
\le
\min{R_{\rm stop},Q_b}+\epsilon.
]

建议直接改成 **T17a-report / T17a-STOP 两个 deterministic checks**。

这是 regression test 的问题，**不是 CR-RBL certificate 本身的数学错误**；G3 的 492/500 certified、0 violations 仍然是有效经验支持。

# 三、第二个问题：(E[Y]<0\Rightarrow g(b)\equiv E[Y]) 这个表述一般不成立

你现在真正正确的 theorem 是：

[
g_x(b)=E[\min(Y_x,b)].
]

由于有限 nested-quantizer DAG 中 (Y_x) 有界，

[
\lim_{b\to\infty}g_x(b)=E[Y_x].
]

而且：

[
g_x(b)\le E[Y_x],
]

因为：

[
\min(Y_x,b)\le Y_x.
]

因此：

[
\boxed{
E[Y_x]<0
\Rightarrow
g_x(b)<0,\quad\forall b\ge0
}
]

从而：

[
\boxed{
b^\star(x)=+\infty.
}
]

这个结论完全正确。

但是代码注释/报告又进一步写了：

> (E[Y_x]<0\Rightarrow g\equiv E[Y]) plateau

**这个一般不成立。**

例如 (Y) 同时有正值和负值、但均值为负，则：

[
g(b)=E[\min(Y,b)]
]

通常会随 (b) 单调上升，最后才趋于 (E[Y])。

恒等：

[
g(b)=E[Y],\quad\forall b\ge0
]

实际上需要更强条件，例如：

[
\boxed{
\operatorname{ess,sup}Y\le0.
}
]

你现在两个 1-bit 状态恰好满足这一特殊结构，所以：

[
g(b)\equiv-6
]

和

[
g(b)\equiv-3.093
]

是正确的数值现象；但不能把“plateau”写成 (E[Y]<0) 的一般推论。

### B0.4b 正式 theorem 建议写成

在 (Y_x) 有界条件下：

[
\boxed{
b^\star(x)<\infty
\iff
E[Y_x]\ge0.
}
]

进一步：

[
E[Y_x]<0
\Rightarrow
b^\star(x)=\infty,
]

且：

[
\operatorname{ess,sup}Y_x\le0
\Rightarrow
g_x(b)\equiv E[Y_x],\quad b\ge0.
]

这样理论就完全严谨了。

# 四、Hoeffding range 的“代码是安全的”，但证明文字需要改一行

现在实现：

# [ D_a(x,h)

\min{
C_{\max}^{rem}(x),h
}
+
R_{\max}
-c_a
]

是安全的。

因为总 radio cost 满足：

[
C_T
\le
\min{
C_{\max}^{rem}(x),h
},
]

而执行动作 (a) 后：

[
G_a=C_T+R_T,
]

且：

[
G_a\ge c_a,\qquad
R_T\le R_{\max}.
]

因此：

[
G_a
\in
\left[
c_a,,
\min{C_{\max}^{rem}(x),h}+R_{\max}
\right].
]

于是 range diameter 正好：

[
\boxed{
D_a=
\min{C_{\max}^{rem}(x),h}
+R_{\max}-c_a.
}
]

但是 `rbl_cr.py` docstring 中间写成：

[
0\le G_a-c_a
\le
\min{
C_{\max}^{rem}(x),
h-c_a
}
+R_{\max}.
]

这和最终公式并不一般等价。

所以不用改代码，只把证明写成上面那个**总 cost upper bound → subtract lower endpoint**的形式即可。

甚至 B0.4 可以进一步收紧成：

# [ D_a

\min{
C_{\max}^{rem}(x;a),
h-c_a
}
+R_{\max},
]

其中 (C_{\max}^{rem}(x;a)) 是**执行首动作 (a) 之后的最大未来通信成本**。

因为你这里每个 action 的 (r_2) 已知，所以 future maximum transaction count 其实可以解析算出。

这是一个免费 tightening，但不是 B0.4 的核心创新。

# 十、candidate–challenger 需要特别注意“adaptive pair sampling”的证书

你计划从：

[

]

降成：

[

]

非常正确。

但是在理论上要明确：

在第 (t) 个 world 抽样前，根据历史：

[
\mathcal F_{t-1}
]

选择：

[
(a_t,b_t).
]

然后才采：

[
W_t\sim P(W\mid x).
]

即：

[
(a_t,b_t)
]

必须是 **predictable** 的。

这样对于每个 pair ((a,b))，它被选择时看到的 (Z_t^{a,b}) 仍具有正确条件均值：

# [ E[ Z_t^{a,b} \mid \mathcal F_{t-1}, (a_t,b_t)=(a,b) ]

\Delta_{a,b}.
]

再给每个 pair 分配：

[
\delta_{ab},
\qquad
\sum_{a<b}\delta_{ab}\le\delta,
]

就能维持 simultaneous validity。

这点一定要在 theorem 中写，因为 B0.4 已经不是“每轮所有动作都观测”的简单情形。
