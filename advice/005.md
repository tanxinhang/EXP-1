# 二、最重要的好消息：C2.1 本身现在是可信的

当前 `run_mvsc021.py` 已经不是以前那种“公式写对了、budget implementation 却错了”的状态。

资源窗已经真正区分：

[
\text{A}:c_1\le h<c_{\rm dir},
]

[
\text{B}:c_{\rm dir}\le h<c_1+c_2,
]

[
\text{C}:h\ge c_1+c_2.
]

并最终落实成：

[
\text{prune}
\iff
\text{direct feasible}
\land
(Q_{\rm prog}-Q_{\rm dir}\ge-\varepsilon).
]

因此 A 区 direct 不可行时，即使某个理论 `g>=0`，也不能把唯一可行的 probe 删掉。这是符合 constrained decision 基本逻辑的。

- 一条路径：`Q_prog-Q_dir`；

- support 形式 (E[\min(Y,b)])；
- strategy-value 形式 (Q_{\rm prog}-Q_{\rm dir})。

而且 sabotage `Q_prog+5`、`E_dir+5`、`E_R` 偏移会真正触发 FAIL。

所以：

> **不要再围绕 C2.1 的 Region-B / identity gate 继续打补丁。**

这里已经足够收口。

# 六、P0：当前还没有遵守 SystemModel 自己规定的 randomized-policy 逻辑

> constrained optimum 不一定对应一个 deterministic policy；必要时应在相邻 deterministic policies 间 episode-level randomized mixture。

# [ \hat\theta

\arg\min_{\theta\in\Theta}
E[B_\theta]

subject to 单个 deterministic grid point feasible。

没有计算不同 controller 点的 convex hull。

因此现在只能说：

> **registered deterministic finite grid infeasible**。

### 正确操作

把每个 deterministic policy 映射成：

[

(P_{FA,\theta},

# [ v_\lambda

\lambda v_{\theta_1}

(1-\lambda)v_{\theta_2}.

因为 error probabilities 和 expected cost 对这种外部随机化都是线性的。

先求：

[
\operatorname{conv}{v_\theta},

再判断是否与

[
P_{FA}\le\alpha,\qquad P_{MD}\le\beta

相交。

**这一步必须发生在 C3c“信息论不可达”之前。**

# 九、`P_D,max` 还有一个细微但重要的 Neyman–Pearson 问题

现在 MITM reference 的 statistic 是**离散**的。

代码采用：

[
\Omega>\eta
]

并通过 bisection 找一个 deterministic threshold，使：

[
P_{FA}\le\alpha.
]

这是一个确定性阈值 reference。

但是对于离散 LLR，严格意义上的 NP optimum 可以在 boundary mass 上随机化：

[
\delta(\Omega=\eta)=1
\quad\text{with probability }\gamma.
]

这样可以把剩余 false-alarm budget 用满。

所以目前的：

[
P_{D,\max}=0.8509
]

更严谨的名称其实是：

[
\boxed{P_{D,\max}^{\rm det-thr}}.
]

有两种处理方式：

1. **最推荐**：MITM 直接实现 randomized NP boundary，得到真正的 (P_{D,\max})；
2. 如果为了算法统一坚持 deterministic final decision，就明确写成 deterministic-threshold achievable reference。

不要一边叫 “maximum achievable” 一边又限制为 deterministic threshold 而不说明。

# 十五、创新性重新判断

现有文献已经覆盖很多相邻机制：

- successive-refinement hypothesis testing 已有很早的信息论研究；([IBM Research](https://research.ibm.com/publications/hypothesis-testing-under-successive-refinement-communication-constraints?utm_source=chatgpt.com))
- ordered transmission / early stopping 已经非常成熟；([开放获取期刊目录](https://doaj.org/article/1519e60a7e9d4a0ab4a6301d2ca35f6d?utm_source=chatgpt.com))
- FE-SRTS 已经把 feedback、ordered transmission、quantization、fading/retransmission 等结合到 distributed detection；([Indian Institute of Science](https://ece.iisc.ac.in/~nextgenwrl/papers/Sayantan_2024_TCOM.pdf?utm_source=chatgpt.com))
- 2026 multi-TRP UAV ISAC 工作也已经明确量化 cooperative sensing overhead。([arXiv](https://arxiv.org/abs/2604.26113?utm_source=chatgpt.com))

因此千万不要写：

> 首次提出渐进证据传输。

也不要写：

> 首次利用反馈动态决定是否继续发送。

都很危险。

### 当前真正可以继续拔高的创新是

[
\boxed{
\textbf{Feedback-Granularity-Aware Adaptive Evidence Acquisition}
}
]

更具体地：

> 在存在 **per-transaction setup/control cost、hard reporting window 和 heterogeneous U2U resource cost** 时，根据已揭示 evidence 的实际 realization，自适应选择 UAV 与 evidence precision，并建立 **state-dependent packetization phase law**。

最核心理论应该从现在的：

# [ g_x(b)

E[\min(Y_x,b)]
]

升级成完整的 **budget-aware link-dependent theorem**：

# [ \boxed{ g_{s,i}(b_i)

E[
\min{
D_{s,i}(X_1)-d_{2,i},
b_i
}
]
}
]

并与当前 A/B/C resource regions 统一。

这样论文不是“又一个边际收益 greedy”，而是：

> **什么时候 coarse-first feedback acquisition 在物理 transaction overhead 和 remaining frame budget 下值得执行，以及什么时候应直接 jump。**

这才是当前项目最强的理论中心。
