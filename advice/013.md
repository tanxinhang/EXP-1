# B0.4b 应该做什么

建议 B0.4b **纯理论封板，不再优化 planner**。核心目标不是再次证明已有的

[
b^\star(x)<\infty
\iff
\mathbb E[Y_x]\ge0,
]

而是把它提升成完整的 **Feedback-Granularity Phase-Transition Theorem**。

当前代码已经有正确核心恒等式：

# [ g_x(b)

# Q_{\rm prog}(x;b)-Q_{\rm dir}(x;b)

\mathbb E[\min{Y_x,b}],
]

其中

[
Y_x=D(X_1)-\Delta_2,
]

# [ D(X_1)

## R(X_1)

\mathbb E[R(X_2)\mid X_1].
]

这在现有 `g_state()` 中已经按两种形式独立计算。

## 1. 建议正式写成下面这个主定理

设当前证据状态为 (x)，当前量化层为 (r)，先渐进到 (r_1)，完整报告到 (r_2)，且

[
\Delta_2=r_2-r_1.
]

每次 transaction 的固定 setup/header 开销为 (b\ge0)。

定义第二阶段纯信息收益

# [ D_x(X_1)

## R(X_1)

\mathbb E[R(X_2)\mid X_1],
]

以及

[
Y_x=D_x(X_1)-\Delta_2.
]

那么：

# [ \boxed{ Q_{\rm prog}(x;b)-Q_{\rm dir}(x;b)

# g_x(b)

\mathbb E[\min{Y_x,b}]
}
]

并且：

[
\boxed{
g_x(0)=-\mathbb E[Y_x^-]\le0
}
]

以及

[
\boxed{
\lim_{b\to\infty}g_x(b)=\mathbb E[Y_x].
}
]

因为 Bayes risk 对 posterior 是凹函数，posterior 又满足 martingale property，因此

[
D_x(X_1)\ge0.
]

同时

[
D_x(X_1)\le R_{\max},
]

故

[
-\Delta_2
\le Y_x
\le R_{\max}-\Delta_2.
]

所以这里 (Y_x) 天然有界，不需要额外人为 boundedness 假设。

# 2. 最值得写进论文的新性质：导数就是“继续第二次反馈”的概率

这一点比单纯“凹函数”更有物理解释。

对于

[
g_x(b)=\mathbb E[\min(Y_x,b)],
]

有

[
\boxed{
g'_{x,+}(b)=
\Pr(Y_x>b)
}
]

以及

[
\boxed{
g'_{x,-}(b)=
\Pr(Y_x\ge b).
}
]

如果 (b) 不是 (Y_x) 的原子点：

[
\boxed{
g_x'(b)=\Pr(Y_x>b).
}
]

而 progressive policy 第二次 transaction 的条件正好是

[
D(X_1)>
b+\Delta_2,
]

即

[
Y_x>b.
]

所以得到一个非常漂亮的物理解释：

# [ \boxed{ \frac{\partial}{\partial b} \big( Q_{\rm prog}-Q_{\rm dir} \big)

P(\text{second transaction is triggered}).
}
]

也就是说：

> **setup cost 对 packetization preference 的边际影响，恰好等于额外反馈 transaction 的触发概率。**

这个结果比“存在一个 threshold”更像论文主定理。

现有 G6 已经数值验证过 survival probability 与导数吻合，例如 root 状态 survival 为 0.5。

# 3. (b^\star(x)) 的完整分类必须分三种情况

定义

# [ b^\star(x)

\inf{b\ge0:g_x(b)\ge0}.
]

### Case A：(\mathbb E[Y_x]<0)

因为

[
\min(Y_x,b)\le Y_x,
]

所以

[
g_x(b)\le \mathbb E[Y_x]<0
\qquad\forall b\ge0.
]

因此：

[
\boxed{
b^\star(x)=+\infty.
}
]

即 progressive 永远严格优于 direct。

这与你当前两个 1-bit 子状态完全一致：

[
E[Y]=-6,
\qquad
E[Y]=-3.0932,
]

均得到 (b^\star=\infty)。

------

### Case B：(\mathbb E[Y_x]=0)

这是目前文档最容易被遗漏的边界情况。

此时

[
g_x(b)\le0.
]

由于本模型 (Y_x) 有界，令

[
y_{\max}=\operatorname{ess,sup}Y_x,
]

则对于

[
b\ge y_{\max},
]

有

[
g_x(b)=E[Y_x]=0.
]

因此

[
\boxed{
b^\star(x)=\max{0,\operatorname{ess,sup}Y_x}.
}
]

但注意：

> 此时 (b>b^\star) 后不是 direct 严格优于 progressive，而是**两者持平**。

所以 B0.4b 后 README/论文不能笼统写：

> (b>b^\star\Rightarrow) direct dominates。

严格地说只有 (E[Y]>0) 才成立。

------

### Case C：(\mathbb E[Y_x]>0)

若 (P(Y_x<0)>0)，则

[
g_x(0)<0,
]

而

[
g_x(\infty)=E[Y_x]>0.
]

由连续性、单调性可知存在有限 crossing，而且是唯一 crossing：

[
\boxed{
0<b^\star(x)
<
\operatorname{ess,sup}Y_x.
}
]

并且

[
b<b^\star
\Rightarrow
Q_{\rm prog}<Q_{\rm dir},
]

[
b=b^\star
\Rightarrow
Q_{\rm prog}=Q_{\rm dir},
]

[
b>b^\star
\Rightarrow
Q_{\rm prog}>Q_{\rm dir}.
]

如果 (Y_x\ge0) a.s.，则特殊地

[
b^\star=0.
]

因此最终可以正式得到：

[
\boxed{
b^\star(x)<\infty
\iff
E[Y_x]\ge0
}
]

但这个 iff 应明确注明：

> **在本模型的 bounded Bayes-risk / finite evidence setting 下。**

# 4. 更物理的存在性判据

因为

[
Y_x=D_x-\Delta_2,
]

所以：

# [ E[Y_x]

E[D_x]-\Delta_2.
]

因此：

[
\boxed{
b^\star(x)<\infty
\iff
E[D_x]\ge\Delta_2.
}
]

这其实比 (E[Y]) 更适合写进通信论文：

> packetization phase boundary 存在，当且仅当**第二阶段额外证据带来的期望 Bayes-risk reduction**至少能够补偿完整包相对于粗粒度包增加的 payload cost。

这很好地把 sensing 与 communication 放到了一个式子里：

[
\underbrace{E[D_x]}*{\text{sensing/evidence value}}
\quad\text{vs}\quad
\underbrace{\Delta_2}*{\text{communication payload}}.
]

而 (b) 控制的是：

[
\text{feedback granularity / transaction frequency}.
]

这正是当前项目真正有创新性的地方。

# 5. 不要再用 grid interpolation 算 (b^\star)

当前 G6 用 `bstar_from_grid()` 做线性插值。

B0.4b 应该改成**exact support computation**。

因为

# [ g_x(b)

E[Y_x]-E[(Y_x-b)_+].
]

如果

[
Y_x\in{y_1,\ldots,y_K},
\qquad
P(Y_x=y_k)=p_k,
]

那么 (g_x(b)) 是精确 piecewise-linear。

把正的 (y_k) 排序后，在每个 interval 中：

# [ g_x'(b)

\sum_{y_k>b}p_k
]

是常数。

因此 crossing 可以直接求：

# [ \boxed{ b^\star

b_0-\frac{g_x(b_0)}
{\Pr(Y_x>b_0)}
}
]

其中 (b_0) 是包含 crossing 的左端 support breakpoint。

当前 root 状态就是最漂亮的例子：

[
Y_x=
\begin{cases}
-7,&p=0.5,\
84.1187,&p=0.5,
\end{cases}
]

所以：

[
g(0)=-3.5,
\qquad
g'(b)=0.5
]

直到 crossing，因此：

# [ b^\star

# 0-\frac{-3.5}{0.5}

\boxed{7}.
]

这比“grid≈8、插值=7”干净很多。现有报告中的数值已经支持这个解析结构。
