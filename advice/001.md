# 一、深度审计后的总判断

我把当前仓库拆成四层看：

\boxed{\text{什么时候值得先发小 evidence packet，再根据结果决定是否继续？}}
]

这才应该成为下一版系统的理论主轴。

# 二、P0-1：目前最大的结构问题是“论文对象”和“真正运行的算法”不是同一个

`SystemModel.md` 明确把：

- O-PEF-1：depth-1，低复杂度 ablation；
- O-PEF-2：depth-2，**主算法**；

区分开，并指出 depth-2 的目的正是捕捉：

[
\text{probe}\rightarrow\text{conditional refinement}.
]

但当前 G2 的正式算法实际是：

# [ Q^{(1)}_{\rho,\eta}(a|x,h)

c_a+\mathbb E[R_{\rho,\eta}(X')|x,a],
]

然后每次收到新证据后 receding re-plan。也就是说，本质仍是 **one-step lookahead**。

这并不是错。

但现在出现了：

[
\boxed{
\text{SystemModel 主张 OPEF-2}
\neq
\text{G2 实际认证 OPEF-1-style controller}.
}
]

更麻烦的是，仓库里真正的 `OPEF2` 只存在于 N=4 eager table 路径：

# [ Q_a^{(2)}

c_a+E[V_1(X')],
]

还没有成为 N=8 sparse 主算法。

### 结论

不要再把 G3 接在当前 q1 controller 上就叫“最终 O-PEF”。

应该先解决：

[
\boxed{\text{主算法到底是一阶 myopic，还是显式 conditional-refinement policy？}}
]

我的答案是：**应该升级为一个受理论约束的轻量二阶 conditional-refinement policy，但不要回到昂贵的 full depth-2 / CPI planner。**

后面给具体形式。

# 三、P0-2：当前 G2 的 QoS 与 SystemModel 的论文主问题不是一个问题

这个问题比 G3 更重要。

`SystemModel.md` 的主检测目标一直是：

[
P_{FA}=0.05,
]

并要求：

[
P_{D,\pi}
\ge
P_{D,\max}-0.01.
]

也就是“在几乎不损失最高精度全节点检测性能的情况下省通信”。

但当前 G2 正式注册的是：

[
P_{FA}\le0.12,
\qquad
P_{MD}\le0.40.
]

也就是只需要：

[
P_D\ge0.60.
]

当前 H=96 测试结果：

[
P_{FA}^{FG}=0.0756,
\qquad
P_{MD}^{FG}=0.2894,
]

所以：

[
P_D^{FG}=0.7106.
]

而对当前 N=8 Gaussian sensing strength

[
[-4,-3,-2,-1,0,1,2,3]\text{ dB},
]

连续 full-fusion 在 (P_{FA}=0.05) 下已经约有

[
P_{D,\rm raw}\approx0.887,
]

8-bit reference 通常应接近这一量级。

所以：

[
\boxed{
\text{G2 PASS 是真实的，但它不能作为 SystemModel 中 matched-detection 主结论。}
}
]

这是当前最需要在论文架构上纠正的地方。

### 正确做法

最终 paper-level QoS 应统一成：

[
\boxed{
P_{FA}\le\alpha
}
]

和

[
\boxed{
P_D\ge P_{D,\max}(\alpha)-\epsilon_D.
}
]

例如：

[
\alpha=0.05,\qquad \epsilon_D=0.01.
]

等价于：

[
P_{MD}
\le
1-P_{D,\max}+0.01.
]

而不是先人为设一个 (\beta=0.40)。

这样“感知要求”来自 full-report reference，而不是来自算法方便通过的阈值。

这是很大的定位差异。

# 五、当前 `16+Δr` 还漏掉了一个对 FG 非常关键的物理成本：反馈/查询控制

你的机制本质是：

> fusion UAV 看完当前 evidence 后，决定“下一个 UAV 发什么精度”。

那么每一个动作

[
a=(i,r\rightarrow r')
]

原则上不仅包括 sensor→fusion 的 evidence packet，还存在：

[
\text{fusion}\rightarrow\text{UAV}
]

的 request/control。

至少需要说明：

- 请求哪个 UAV；
- 请求哪个 precision/refinement；
- 调度资源；
- 可能的 ACK/NACK。

FE-SRTS 已经明确将 fusion-node feedback、ordered transmissions、quantization、fading 等放在同一个 distributed-detection protocol 里，因此“有 feedback”本身显然不能作为创新；反过来，你如果研究 feedback granularity，却把 feedback cost 完全免费，就会成为很容易被问的问题。([印度科技学院电子与通信工程系](https://ece.iisc.ac.in/~nextgenwrl/papers/Sayantan_2024_TCOM.pdf?utm_source=chatgpt.com))

### 建议重新定义一次 transaction

令：

# [ b_{0,i}

b_{\rm req,i}
+
b_{\rm hdr,i}
+
b_{\rm crc,i}
+
b_{\rm ack,i},
]

则一次 refinement 的物理资源为：

# [ \boxed{ c_{i,r\rightarrow r'}

b_{0,i}
+
d_i(r,r').
}
]

最简单：

# [ d_i(r,r')

\kappa_i(r'-r),
]

其中：

[
\kappa_i
]

把每个 evidence bit 转换成该 U2U link 上的 effective channel-resource cost。

这样现在的：

[
16+\Delta r
]

只是特殊情况：

[
b_{0,i}=16,\qquad \kappa_i=1.
]

这样不会推翻已有结果，而是把它变成新模型的 homogeneous special case。

# 六、我建议主通信指标从“radio bits”升级为“两层指标”

不要完全放弃 bit。

而是区分：

### 机制指标

[
B_{\rm evidence}
]

表示真正揭示了多少 evidence bit。

用于说明：

> adaptive packetization 是否减少了不必要的信息揭示。

### 物理指标

[
C_{\rm U2U}
]

表示实际占用的无线资源，例如 channel uses / airtime-normalized resource：

# [ \boxed{ C_a

C_{{\rm ctrl},a}
+
\frac{B_{\rm hdr}+\Delta r}
{\eta_i^{\rm eff}}
}
]

若考虑 memoryless retry-to-success：

[
C_a
\approx
C_{{\rm ctrl},a}
+
\frac{B_{\rm hdr}+\Delta r}
{\eta_i^{\rm eff}p_i^{succ}}.
]

主优化使用：

[
E[C_{\rm U2U}],
]

而同时报告：

[
E[B_{\rm evidence}].
]

这会比只说“省了 5 bits”强很多。

2026 年最新 networked/multi-TRP ISAC 工作已经越来越强调 overhead、latency、resource occupation，而不是只看 sensing gain；例如 3GPP-oriented multi-TRP UAV detection 明确量化了多个 TRP 带来的 sensing overhead，当前 ISAC evaluation methodology 也强调 signaling/control overhead 和 latency 必须进入 end-to-end 评价。([arXiv](https://arxiv.org/abs/2604.26113?utm_source=chatgpt.com))

# 七、P0-4：当前 H=96/48 是一个真实的 hard constraint，但正式优化问题没有它

当前 G2 所有动作都必须满足：

[
c_a\le h,
]

且逐路径：

[
B_{\rm episode}\le H.
]

但是 SystemModel 当前正式问题是：

[
\min_\pi E[C_\pi]
]

subject to：

[
P_{FA}\le\alpha,\qquad P_M\le\beta.
]

里面没有：

[
C_\pi\le H
]

这个 pathwise constraint。

所以当前真正解决的是：

[
\boxed{
\min_\pi E[C_\pi]
}
]

s.t.

[
P_{FA}\le\alpha,
]

[
P_M\le\beta,
]

[
\boxed{
C_\pi(\omega)\le H
\quad\text{a.s.}
}
]

而不是 SystemModel 写的那个问题。

这不是小细节。

因为 H=96 时：

- fresh FG 最小 transaction = 17；
- fresh Direct8 = 24；

所以 Direct8 最多只能 full-report 4 个 UAV：

[
4\times24=96.
]

FG 则可以利用更细 packet 做不同的 budget packing。

这本身可以是 granularity 的真实价值，但必须承认它属于：

[
\boxed{\text{hard report-window constrained evidence acquisition}}
]

而不仅仅是“平均 bits 最小化”。

### 我建议保留 H

因为在无线系统中，一个 sensing/reporting frame 本来就有有限 reporting window。

但应该把它物理化：

[
C_{\rm U2U}(\omega)\le C_{\max}^{frame}.
]

而不是把 H 叫 planner horizon。

这样 hard budget 就从算法技巧变成通信约束。

# 八、最终数学问题应该重写成这个版本

我认为这一版比当前 SystemModel 更完整：

给定慢时变 context：

[
\xi=
{\xi_i^{sense},\xi_i^{link}}_{i=1}^N,
]

其中 sensing context 决定：

[
P(M_i^{(r)}=m|H_h,\xi_i^{sense}),
]

link context 决定：

[
c_{i,r\rightarrow r'}(\xi_i^{link}).
]

状态：

[
\boxed{
s=(\mathbf z,h;\xi)
}
]

其中：

- (\mathbf z)：已揭示 evidence cell；
- (h)：剩余 U2U frame resource；
- (\xi)：慢时变 context，episode 内已知。

优化：

[
\boxed{
\min_{\pi}
E_\pi[C]
}
]

s.t.

[
P_{FA}^{\pi}\le\alpha,
]

[
P_D^\pi
\ge
P_{D,\max}(\alpha)-\epsilon_D,
]

[
C(\omega)\le C_{\max}^{frame}
\quad a.s.
]

动作：

[
\boxed{
a=(i,r_i\rightarrow r_i')
}
]

或者 STOP。

将 error constraints dualize 后：

# [ R_\lambda(s)

\min{
\bar\lambda_M p_s,
\bar\lambda_F(1-p_s)
}.
]

Bellman：

# [ \boxed{ V_\lambda^\star(s)

\min
\left{
R_\lambda(s),
\min_{a:c_a\le h}
\left[
c_a+
E[V_\lambda^\star(S')|s,a]
\right]
\right}.
}
]

这和现有 SparsePlanner 的数学骨架完全一致，只需要把：

[
c_a=16+\Delta r
]

抽象成：

[
c_a=\mathcal C(i,r,r',\xi_i^{link}).
]

# 九、最重要的算法调整：不要回到昂贵 full-depth planner，而是利用现有 phase theorem 构造“理论指导的轻量二阶策略”

这是我认为最值得做的创新。

当前 one-step 对 probe：

# [ Q^{(1)}_{\rm probe}

c_p+E[R(X_1)].
]

它把 probe 之后当成马上停止。

因此会**系统性低估“先看一小包，再根据结果决定是否继续”的价值**。

而这正是你的创新机制。

## 9.1 对每个 UAV 只考虑两种结构动作

设当前 precision 为 (r)。

定义：

# [ r_+

\text{next precision level}.
]

只比较：

### Probe

[
r\rightarrow r_+
]

### Jump

[
r\rightarrow r_{\max}.
]

不要一上来同时枚举：

[
r\to1,2,4,8
]

所有跳跃。

原因：

1. 降 action complexity；
2. 理论可以精确比较 probe vs jump；
3. receding 后仍能产生：

[
0\to1\to2\to8,
]

或：

[
0\to1\to4,
]

等 realized-message-dependent path。

# 十、定义新的 conditional-refinement value

Direct：

# [ Q^{dir}_i(s)

c_i(r,r_{\max})
+
E[R(S_i^{max})].
]

Progressive：

# [ \boxed{ Q^{prog}_i(s)

c_i(r,r_+)
+
E\left[
\min
\left{
R(S_i^+),
c_i(r_+,r_{\max})
+
E[R(S_i^{max})|S_i^+]
\right}
\right].
}
]

然后：

# [ Q_i^{local}(s)

\min{Q_i^{dir},Q_i^{prog}}.
]

全局：

# [ i^\star

\arg\min_i Q_i^{local}(s).
]

如果：

[
R(s)
\le
\min_iQ_i^{local}(s),
]

STOP。

否则执行对应的 probe 或 direct jump。

收到真实 message 后：

[
s\rightarrow s',
]

再次对**所有 UAV**重新规划。

# 十一、这个架构有一个非常漂亮的理论 sandwich

定义真正 global depth-2 continuation：

# [ V_1^{global}(s')

\min\left{
R(s'),
\min_b
[c_b+ER(s'')]
\right}.
]

而我们只允许：

- STOP；
- 对同一 UAV 补到 full；

得到：

[
V_1^{self}(s').
]

显然动作集合包含关系给出：

[
\boxed{
V_1^{global}(s')
\le
V_1^{self}(s')
\le
R(s').
}
]

因此：

[
\boxed{
Q_a^{global-2}
\le
Q_a^{self-2}
\le
Q_a^{(1)}.
}
]

这非常有意义：

- 比 current G2 one-step 更少 myopic；
- 比完整 O-PEF-2 便宜；
- 而且是一个**保守近似**，不会凭空虚构未来收益。

这比 G3 的 Monte-Carlo CPI planner 更适合作为主算法升级。

# 十二、更重要的是：现有 phase theorem 可以直接推广到异质 U2U link

这是真正值得理论拔高的地方。

设：

[
c_p=b_i+d_{1,i},
]

[
c_s=b_i+d_{2,i},
]

[
c_d=b_i+d_{1,i}+d_{2,i}.
]

其中：

- (b_i)：一次 transaction 的 fixed control/setup cost；
- (d_{1,i})：probe payload resource；
- (d_{2,i})：剩余 refinement resource。

定义：

# [ D_{s,i}(X_1)

## R(X_1)

E[R(X_2)|X_1].
]

那么：

[
Q_i^{prog}-Q_i^{dir}
]

可以严格化简为：

# [ \boxed{ g_{s,i}(b_i)

E\left[
\min
\left{
D_{s,i}(X_1)-d_{2,i},
b_i
\right}
\right].
}
]

也就是原 theorem：

[
g_x(b)=E[\min(Y_x,b)]
]

的**link-aware generalization**，其中：

# [ Y_{s,i}

D_{s,i}-d_{2,i}.
]

原有 theorem 不需要推翻，只需要把：

[
\Delta_2=r_{\max}-r_+
]

从“bit difference”提升成：

# [ \boxed{ d_{2,i}

\text{link-dependent incremental communication resource}.
}
]

这会把 sensing 和 communication 真正连起来。

------

# 十三、由此可以得到新的 Link-Aware Packetization Phase Boundary

定义：

# [ b_{s,i}^\star

\inf
{
b\ge0:g_{s,i}(b)\ge0
}.
]

那么：

[
b_i<b_{s,i}^\star
]

时 progressive probe 更好；

而：

[
b_i>b_{s,i}^\star
]

时 direct jump 更好。

并且仍然有：

# [ \frac{\partial^+ g_{s,i}(b)} {\partial b}

P(Y_{s,i}>b).
]

物理解释非常漂亮：

# [ \boxed{ \text{setup overhead 对 progressive packetization 的边际惩罚}

\text{第二次 refinement 实际被触发的概率}.
}
]

这已经不是“老套的边际收益”。

这是一个**feedback granularity phase law**。

------

# 十四、进一步可以把 phase theorem 直接用于安全剪枝

若：

[
g_{s,i}(b_i)\ge0,
]

那么对 UAV (i)：

[
Q_i^{prog}\ge Q_i^{dir}.
]

所以 probe 在该 UAV 上可以直接删掉。

因此定义：

# [ \mathcal A_{\rm keep}(s)

{
a_i^{dir}
}
\cup
{
a_i^{probe}:g_{s,i}(b_i)<0
}.
]

这是：

[
\boxed{
\textbf{theory-certified phase-guided action pruning}
}
]

不是 heuristic Top-K。

复杂度从一般 cross-level action：

[
O(N|\mathcal R|)
]

缩到最多：

[
O(2N),
]

并且大量 UAV 在 direct region 下只保留一个动作。

这比在 G3 上做几千次 Monte-Carlo rollout 来决定 action 更符合当前论文核心。

# 十五、packet loss 也可以自然加入，不需要直接把 DAG 打碎

先考虑 retry-until-success。

若：

[
p_i^{succ}
]

为一次成功概率，则定义 effective resource：

# [ \bar b_i

\frac{b_i}{p_i^{succ}},
]

# [ \bar d_i

\frac{d_i}{p_i^{succ}}.
]

那么 link-aware phase theorem 的形式完全不变：

# [ g_{s,i}(\bar b_i)

E[\min(D_{s,i}-\bar d_{2,i},\bar b_i)].
]

所以可以先用：

[
\boxed{\text{collapsed reliable-service model}}
]

作为主模型。

但必须诚实：

如果 packet failure 后允许：

> 换一个 UAV，而不是坚持重传当前 action，

那么：

[
c/p_i^{succ}
]

不再严格等价于 explicit failure MDP，因为 failure 后存在 option value。

因此 B1 可以专门验证：

[
\text{retry-until-success abstraction}
]

和：

[
\text{explicit failure + replan}
]

之间的 gap。

这本身还可以形成一个小 theorem：

> collapsed (c/p) exact 当且仅当 failure 后策略承诺继续相同 action，或者等价条件成立。

不要现在塞进主算法。

# 十六、当前 sensing abstraction 可以保留，但要增加一个“经验 PMF 接口”

现在 Gaussian：

[
H_0:X_i\sim N(0,1),
\qquad
H_1:X_i\sim N(a_i,1)
]

非常适合理论验证。

不要删除。

但最终代码不要让算法只能接受 `GaussianDetectorModel`。

应该形成：

```text
EvidenceModel
├── GaussianEvidenceModel        # theorem/oracle
└── EmpiricalCalibratedModel     # waveform / OTFS / trace
```

后者只需提供：

[
P(M_i^{(r)}=m|H_h,\xi_i).
]

这样算法层完全不用知道底下是：

- OTFS GLRT；

\boxed{
\text{每一次局部审计都越来越正确，
但整体研究对象开始被历史修补链拖散。}
}
]

最应该保留的是四样东西：

[
\boxed{
\text{nested evidence}
+
\text{message-consistent Bayesian fusion}
+
\text{exact small-N CMDP oracle}
+
\text{packetization phase theory}.
}
]

最应该砍掉或降级的是：

[
\boxed{
\text{把复杂 CPI/certificate planner 当主创新的路线}.
}
]

下一版真正值得做的是：

[
\boxed{
\textbf{Link-Aware, Phase-Guided, Realization-Conditioned Evidence Acquisition}
}
]

即把现有的 feedback granularity 从一个“实验上有效的 q1 action space”升级为：

> **由状态依赖 packetization phase law 决定 probe/jump，并显式考虑 U2U transaction/control/reliability cost 的协同证据通信机制。**

这条路线在数学上能从现有 `phase_boundary.py` 自然推导，不需要生造理论；在通信上把 feedback/control、link heterogeneity 和 hard reporting window 补齐；在感知上继续坚持 soft evidence + matched detection QoS；在创新上也明显比继续做 G3/CPI 更集中。

**因此我当前建议是：冻结 B0.7/G2，不实现 G3；下一步直接做架构级 C0→C1，先重写最终 System Model 和 core interfaces，再实现新算法。**
