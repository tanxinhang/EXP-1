# 3. 本轮 0.088 → 0.870 的改善不能全部归因于 paired CRN

这是论文叙事上非常关键的一点。

这轮实际上同时修了两个完全不同的东西：

### A. probability-model correction

旧实现：

[
\prod_i
P(M_i^{(8)}\mid x)
]

错误地把不同 UAV marginal 独立抽样。

正确模型：

# [ \boxed{ P(W\mid x)

\sum_h
P(h\mid x)
\prod_i
P(M_i^{(8)}\mid H=h,x_i).
}
]

这消除了大约 (12) bits 的 **bias**。

### B. variance reduction

在正确 world 下再令：

[
W_m
]

由所有动作共享：

[
G_a(W_m),\quad G_b(W_m),
]

才产生：

[
\frac{
\operatorname{Var}(G_a-G_b)
}{
\operatorname{Var}(G_a)+\operatorname{Var}(G_b)
}
\approx0.08\sim0.15.
]

也就是 **variance reduction**。

这两者不能混成一句：

> paired CRN 把 match 从 8.8% 提高到 87%。

因为其中很可能很大一部分是**消除了错误 joint model 带来的 bias**。

而且 2026 年已经有专门研究 common random numbers 在 rollout planning 中降低 relative-utility variance 的工作，因此“rollout + CRN”本身不能作为主要创新。([alphaXiv](https://www.alphaxiv.org/abs/2605.04732?utm_source=chatgpt.com))

我强烈建议 B0.3c 加一个三格 ablation：

| world distribution | action coupling | 作用                          |
| ------------------ | --------------- | ----------------------------- |
| marginal-product   | independent     | 原 B0.3                       |
| **joint-H**        | independent     | 单独测 **bias correction**    |
| **joint-H**        | **paired**      | 单独测 **variance reduction** |

分别报告：

[
|\hat Q_a-Q_a^{\pi_b}|,
]

[
P(a=a_{\pi_b}^\star),
]

以及：

[
\operatorname{Var}(\hat Q_a-\hat Q_b).
]

这个表对于论文价值很高。
