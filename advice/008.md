## 1. StaticProg 停止语义修正（007 审计发现，先修）

原实现用 QoS-dual `R ≤ min_a Q^(1)` 停止，在 root 处 R<Q 恒成立 ⇒ **23/28
网格点 E[B]=0 全停退化**（什么都不发）。修正为 **|Ω| ≥ η** early-stop（B11
语义：固定 SNR 顺序 ladder + 阈值停止），rho 仅作 θ̂ 网格同构。修正后：
η=0.8 发 1 个 1-bit（17 bits）、η=1.2 发 2 个（34 bits）——不再全停（T44
锁定）。但 FULL calibration 仍 **0/28 FEASIBLE**（固定顺序简单 ladder 无法
同时满足 α=0.12/β=0.40）——这是 StaticProg 的真实局限，本身即 adaptive
必要性的证据，005 §十八 对照含义保留。

## 4. 关键科学结论

1. **Phase-PJ ≡ Myopic-PJ**（θ̂=(256,0.8) 下 D=0.000，T43 锁定）：conditional
   refinement 在当前 N=8 homogeneous、BH=16 regime 的校准点**不改变决策**——
   第二包 counterfactual 的收紧从不改变 argmin（STOP 规则主导）。但
   **(1024,2.0) 极端 θ 有 4/40 episode 差异且 Phase-PJ 更省**（58 vs 65
   bits）——refinement 有 bite，只在 θ 边角显现。
2. **Myopic-All < Phase-PJ < Direct8**（32.20 < 34.49 < 37.52）：全跳动作空间
   最省，Direct8 最贵；Phase-PJ 居中。
3. **StaticProg 无法达标 matched QoS**（0/28 FEASIBLE）——固定顺序简单
   ladder 的局限，凸显 adaptive selection/precision 的必要性。
4. 四层对照的 UNRESOLVED 是**统计诚实**结果（Hoeffding 界 ±4-7 bits 宽于
   E[B] 差异 2-3 bits，n=1600 不足以认证）——不夸大，留给 C3c frontier 或
   更大样本。
