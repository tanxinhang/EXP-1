# 1. 新发现的 P0：1bit-POTS 其实还没有完全修正确

这次确实修掉了“1-bit evidence 和 seed cost 被重复加入”的旧 bug。

但是现在：

```python
seed_lam = lr1.sum(axis=1)

lam2, cost2 = _ladder(
    ...,
    start_r=1
)

return seed_lam + lam2, seed_cost + cost2
```

而 `_ladder(..., start_r=1)` 内部的 early stopping 判断使用的是：

[
\operatorname{cumsum}(\Delta \ell)
]

而不是：

[
\boxed{
\Lambda_{\rm seed}
+
\operatorname{cumsum}(\Delta\ell)
}
]

更重要的是，它没有检查：

[
|\Lambda_{\rm seed}|\ge\eta_s
]

时是否应该**直接在 1-bit seed 后停止**。

所以目前 POTS 的实际流程仍然变成：

[
\text{全体 1-bit}
\rightarrow
\boxed{\text{至少再 refine 一次}}
\rightarrow
\text{才检查 stopping}.
]

正确流程应该是：

[
\boxed{
\text{1-bit seed}
\rightarrow
\text{检查 stop}
\rightarrow
\text{未 stop 才执行 }1\to2\to4\to8.
}
]

而且后续 stopping statistic 必须是：

# [ \Lambda_t

\Lambda_{\rm seed}
+
\sum_{\tau\le t}\Delta\ell_\tau.
]

这意味着当前报告中的：

[
P_D=0.892,\qquad E[B]\approx508
]

仍然不是最终可信的 POTS baseline。

这条我建议列为：

[
\boxed{\text{P0-1b}}
]

修完重新跑 baseline。很可能 POTS 的通信成本会明显下降，因此会进一步加强 baseline，而不是帮助 O-PEF。

这反而是好事情——论文最终不会被 reviewer 用一个实现更正确的 POTS 推翻。

# 8. B0.3 可以正式进入，但必须先明确“PAC 到底认证什么”

这是最重要的理论边界。

不能直接写：

> Monte-Carlo rollout gives an ((\varepsilon,\delta))-optimal action.

因为如果 leaf 后面采用一个 base policy：

[
\pi_b,
]

采样真正估计的是：

[
Q_a^{\pi_b}(x),
]

而不是：

[
Q_a^\star(x).
]

所以 PAC certificate 首先只能严格保证：

[
\boxed{
Q_{\hat a}^{\pi_b}
\le
\min_aQ_a^{\pi_b}
+\varepsilon
}
]

以概率：

[
\ge1-\delta.
]

这是完全正确、也已经足够强的第一版 theorem。

经典 sparse-sampling planning 早已证明，大状态空间 MDP 可以通过 generative sampling 做与状态空间大小无关的近似在线规划，所以“用了 sampled lookahead”本身不能作为新意。([Tel Aviv University](https://cris.tau.ac.il/en/publications/a-sparse-sampling-algorithm-for-near-optimal-planning-in-large-ma/))

你的创新应该在：

[
\boxed{
\text{variable-cost evidence DAG}
+
\text{feedback granularity}
+
\text{QoS risk}
+
\text{confidence-certified adaptive sampling}.
}
]

# 10. Return 可以得到严格有界区间

这是你系统非常适合 PAC 的地方。

当前 refinement 不可逆，因此剩余 transaction 数有限。

若 UAV (i) 当前 precision 为 (r_i)，剩余最多 transaction 数记：

[
k_i(x).
]

那么剩余最大 radio cost：

# [ C_{\max}^{\rm rem}(x)

\sum_i
\left[
k_i(x)b_{\rm setup}
+
(r_{\max}-r_i)
\right].
]

而 terminal Bayes risk：

# [ R(p)

\min(C_{01}p,C_{10}(1-p))
]

的最大值是：

# [ \boxed{ R_{\max}

\frac{C_{01}C_{10}}
{C_{01}+C_{10}}.
}
]

于是 rollout return 严格满足：

# [ \boxed{ 0\le G\le B(x)

C_{\max}^{\rm rem}(x)+R_{\max}.
}
]

可以直接归一化：

[
Y=G/B(x)\in[0,1].
]

这让 concentration theorem 非常干净。

# 11. 第一版先用 Hoeffding certificate，不要一开始只上 empirical Bernstein

为了避免统计实现本身再次成为审计风险，我建议：

### CR-RBL-H

先用一个绝对可靠的 anytime Hoeffding reference。

给 action (a) 第 (n) 次 sampling 分配：

# [ \delta_{a,n}

\frac{6\delta}
{\pi^2|\mathcal A|n^2}.
]

那么：

[
\sum_a\sum_{n=1}^{\infty}\delta_{a,n}
\le\delta.
]

Hoeffding radius：

# [ r_{a,n}

B_a
\sqrt{
\frac{\log(2/\delta_{a,n})}
{2n}
}.
]

因此无论何时 adaptive stop，都有同时覆盖保证。

# 12. 然后再上 empirical-Bernstein confidence sequence

因为 rollout return variance 很可能远低于最坏范围，所以 Hoeffding 会比较保守。

这时可以换成 variance-adaptive empirical-Bernstein CS。

近期统计文献已经有专门针对 bounded mean 的 empirical-Bernstein confidence sequence，而且 confidence sequence 天然适用于**数据依赖 stopping time**。([数字对象标识符](https://doi.org/10.1093/jrsssb%2Fqkad009))

这一点非常关键：

> 不要用一个普通 fixed-(n) empirical-Bernstein CI，然后每采几个样本就反复检查是否停止。

因为这样会产生 optional-stopping coverage 问题。

B0.3 应明确使用：

[
\boxed{\text{time-uniform confidence sequence}}
]

或者 Hoeffding + (\delta_n) spending。

# 16. 如果想把 PAC 从“相对 rollout”进一步拔高到“相对 (V^\star)”，有一个办法

这一层先不要立刻实现，但理论上非常漂亮。

对于任何 leaf state (x)：

STOP 是一个合法策略，因此：

[
\boxed{
V^\star(x)
\le
R_{\rm stop}(x).
}
]

这是 deterministic upper bound。

另一方面，假设剩余所有 evidence **免费且全部揭示**。

定义：

# [ V_{\rm genie}(x)

E[
R_{\rm stop}(X_{\rm full})
\mid x
].
]

因为它：

- 获取的信息至少和任何实际 policy 一样多；
- 通信代价人为设成 0；

所以：

[
\boxed{
V_{\rm genie}(x)
\le
V^\star(x).
}
]

于是：

[
\boxed{
V_{\rm genie}(x)
\le
V^\star(x)
\le
V^{\pi_b}(x)
\le
R_{\rm stop}(x)
}
]

可以形成一个 **Bellman sandwich**。

若某个 leaf：

[
V^{\pi_b}(x)-V_{\rm genie}(x)
\le\varepsilon_{\rm tail},
]

那么 base rollout bias 自动满足：

[
V^{\pi_b}(x)-V^\star(x)
\le\varepsilon_{\rm tail}.
]

最终：

[
\boxed{
Q^\star_{\hat a}
\le
Q^\star_{a^\star}
+
\varepsilon_{\rm stat}
+
\varepsilon_{\rm tail}
}
]

就有机会变成真正的 global certificate。

这可以作为：

> CR-RBL+

而不是第一版就做。
