# 一、现在最大的科研问题已经变了：Phase-PJ 没有产生作用

C3b 的结果非常关键：

| 方法           | H=96 E[B]   | QoS      |
| -------------- | ----------- | -------- |
| Phase-PJ       | 34.4925     | FEASIBLE |
| Myopic-PJ      | 34.4925     | FEASIBLE |
| **Myopic-All** | **32.1975** | FEASIBLE |
| Direct8        | 37.5225     | FEASIBLE |

而且 Phase-PJ 和 Myopic-PJ 不只是均值接近，而是在注册工作点 (ρ,η)=(256,0.8)(\rho,\eta)=(256,0.8) 下被专门写入 T43 回归：

> ```
> Phase-PJ == Myopic-PJ @ theta_hat (refinement no value at calibrated pt)
> ```

代码注释也承认只有在类似 `(1024,2.0)` 的极端点，两者才偶尔不同。

正式 C3b 报告则给出：

ΔBPhase−MyopicPJ=0,\Delta B_{\rm Phase-MyopicPJ}=0,

34.4925−32.1975=+2.295 bits.34.4925-32.1975=+2.295\ {\rm bits}.

> **Phase-Guided Self-Conditional-Refinement**

在实际选中的 operating point 上并不是一个产生性能改进的机制。

所以我不建议继续通过扩大 MC、换 CI、扩大 (ρ,η)(\rho,\eta) 网格来“救”这个结果。

# 二、为什么会出现这个结果

当前 Phase-PJ 实际只保留每个 UAV 的两种结构动作：

{next,full}.\{\text{next},\text{full}\}.

Phase 版本对 `next` 使用 conditional refinement：

Qprog,Q_{\rm prog},

Myopic-PJ 则使用：

Q(1)=c+E[R(X′)].Q^{(1)} = c+\mathbb E[R(X')].

代码确实把两个动作空间做成一致了，因此 C3b 的因果实验设计比以前正确很多。`phase_decision_budget` 真正计算 `Q_prog/Q_dir` 并做 dominance pruning，这部分数学实现没有明显问题。

问题是：

> **你为了获得一个漂亮的 next-vs-full phase theorem，把算法动作空间压得过窄。**

而 Myopic-All 可以直接：

r→1,2,4,8r\rightarrow1,2,4,8

任意跳转，因此虽然它“更短视”，却有更丰富的 precision action space。

这也是为什么现在出现了一个非常危险的现象：

更复杂的 Phase planning<简单但动作空间更丰富的 Myopic-All\boxed{ \text{更复杂的 Phase planning} < \text{简单但动作空间更丰富的 Myopic-All} }

至少从通信成本点估计来看如此。

# 三、C3c 有一个真正的 P0 逻辑问题

这个问题建议优先修。

C3c 宣称 L2 是：

> deterministic + randomized convex hull 的 policy-class feasibility。

但实际代码不是对**每个方法自己的 policy family**做凸包。

代码先执行：

```python
if ts is None:
    continue
cal_points.append((nm, ...))
```

也就是说：

**只有已经存在 deterministic feasible θ^\hat\theta 的方法才进入 L2。**

StaticProg 因为 `ts=None`，直接被排除了。

随后 `policy_class_feasibility()` 做的是：

> Phase-PJ 的选中点、Myopic-PJ 的选中点、Myopic-All 的选中点、Direct8 的选中点之间相互 mixture。

这不是我们需要回答的问题。

真正应该判断的是：

conv⁡{vθStaticProg:θ∈ΘStatic}\operatorname{conv} \{ v_{\theta}^{\rm StaticProg}: \theta\in\Theta_{\rm Static} \}

是否与 QoS 区域相交。

同样，对 Phase 应该是：

conv⁡{vθPhase:θ∈Θ}.\operatorname{conv} \{ v_\theta^{\rm Phase}:\theta\in\Theta \}.

而不是：

conv⁡{vPhase,vMyopic,vDirect8}.\operatorname{conv} \{ v^{\rm Phase}, v^{\rm Myopic}, v^{\rm Direct8} \}.

因此当前 C3c 的：

> L1 YES + L2 YES + StaticProg L3 NO
> ⇒ StaticProg 只是 registered-grid infeasible

这个推理**目前不成立**。

因为当前 L2 根本没有认证 StaticProg 的 policy family。

这是我认为当前仓库最需要马上修正的 P0。

# 四、L2 的 Wilson mixture 也还不能称“正式认证”

当前实现采用：

kFA(λ)=λkFA,a+(1−λ)kFA,b,k_{\rm FA}(\lambda) = \lambda k_{{\rm FA},a} + (1-\lambda)k_{{\rm FA},b},

于是得到**非整数的“期望 violation count”**，然后直接送进 Wilson upper bound。

代码自己也承认这是：

> “近似证据，正式认证在更大样本的显式 mixture 模拟”。

但正式报告却把 L2 表述成：

> “Wilson U95 口径 policy-class feasibility”。

这里应该降级。

最干净的方案不是继续推导 fractional-count Wilson，而是：

θa,θb,λ\theta_a,\theta_b,\lambda

只在 calibration 上确定，然后在**全新的 test worlds** 中显式抽：

Ze∼Bernoulli(λ),Z_e\sim {\rm Bernoulli}(\lambda),

按 episode 真正运行 policy a/ba/b。

这样最终得到真正整数：

kFA,kMD,k_{\rm FA},\quad k_{\rm MD},

再用 Wilson 即可。

这会比当前写法干净很多。

# 六、C3c 的 L1 结论是“正向成立”，但名称过强

现在所谓 L1 “maximum evidence”实际上只检查：

- strongest 4 × 8 bit；
- strongest 4 × 4 bit；
- weakest 4 × 8 bit。

其中 strongest 4 × 8-bit：

4(16+8)=964(16+8)=96

且

PMD=0.1072<0.4,P_{\rm MD}=0.1072<0.4,

所以已经足够证明：

physical problem is feasible.\boxed{\text{physical problem is feasible}}.

这个 PASS 是成立的。

但不能称：

> “maximum evidence configuration”。

因为预算 96 下还存在：

5×1bit=855\times1{\rm bit}=85

以及大量混合分配，例如不同 UAV 的：

(8,8,4,2,…)(8,8,4,2,\ldots)

组合。

所以建议把 L1 改名为：

> **Constructive Physical Feasibility Certificate**

当前 YES 仍然成立。

但以后如果这个构造 FAIL，**不能反推 physical infeasible**；除非真正解一个 budgeted maximum-evidence oracle。

# 七、我建议不要继续修 Phase-PJ，而是升级成“Generalized Phase Envelope”

这是我认为当前最值得做的理论升级。

你现在的 phase theorem 只研究：

r→rnext→rmax⁡r\rightarrow r_{\rm next}\rightarrow r_{\max}

vs

r→rmax⁡.r\rightarrow r_{\max}.

其实完全可以推广到任意：

r<s<t.r<s<t.

设异质链路通信成本先保持仿射：

ci(r→s)=b0,i+κi(s−r),c_i(r\rightarrow s) = b_{0,i} + \kappa_i(s-r),

其中：

- b0,ib_{0,i}：一次 transaction/control/setup airtime；
- κi\kappa_i：该 U2U link 每 evidence bit 的 airtime cost。

定义：

Qprogs,t=ci(r,s)+E[min⁡{R(Xs),ci(s,t)+E[R(Xt)∣Xs]}],Q_{\rm prog}^{s,t} = c_i(r,s) + \mathbb E \left[ \min \left\{ R(X_s), c_i(s,t) + \mathbb E[R(X_t)\mid X_s] \right\} \right],

而直接跳：

Qdirt=ci(r,t)+E[R(Xt)].Q_{\rm dir}^{t} = c_i(r,t) + \mathbb E[R(X_t)].

令

Di,s,t=R(Xs)−E[R(Xt)∣Xs],D_{i,s,t} = R(X_s) - \mathbb E[R(X_t)\mid X_s],

再定义：

Yi,s,t=Di,s,t−κi(t−s).Y_{i,s,t} = D_{i,s,t} - \kappa_i(t-s).

则可以直接得到：

Qprogs,t−Qdirt=E[min⁡{Yi,s,t,b0,i}]\boxed{ Q_{\rm prog}^{s,t} - Q_{\rm dir}^{t} = \mathbb E [ \min\{Y_{i,s,t},b_{0,i}\} ] }

在两步均预算可行的区域成立。

这其实就是你现有 phase theorem 的真正一般形式。

它的价值非常大：

feedback granularity phase+arbitrary precision jump+heterogeneous link cost\boxed{ \text{feedback granularity phase} + \text{arbitrary precision jump} + \text{heterogeneous link cost} }

被统一到一个式子里。

# 八、这个升级正好解决当前 Myopic-All 更强的问题

新的 proposed 不再是：

APhase={next,full},\mathcal A_{\rm Phase} = \{\text{next},\text{full}\},

而是保留：

A={(i,r→s):s>r}\boxed{ \mathcal A = \{(i,r\rightarrow s):s>r\} }

也就是与 Myopic-All 一样完整的 precision action space。

然后对每个：

r<s<tr<s<t

建立 phase dominance edge。

于是算法变成：

Full multi-resolution candidate set→phase-envelope pruning→conditional-refinement Q→action.\text{Full multi-resolution candidate set} \rightarrow \text{phase-envelope pruning} \rightarrow \text{conditional-refinement Q} \rightarrow \text{action}.

我会把这个方向暂称为：

> **Generalized Phase-Envelope Evidence Acquisition，GPE-EA**

或者论文风格更强一些：

> **Link-Aware Phase-Envelope Adaptive Evidence Acquisition**

它比当前 Phase-PJ 的理论完整得多。

更重要的是，它不会为了 theorem 而牺牲 Myopic-All 已经证明有用的跨级跳转能力。

SystemModel 已经把论文核心定位为：

adaptive UAV+adaptive precision+realized feedback+heterogeneous U2U cost.\text{adaptive UAV} + \text{adaptive precision} + \text{realized feedback} + \text{heterogeneous U2U cost}.

b0,i≡τctrl,i,κi≡1Ri,b_{0,i}\equiv\tau_{{\rm ctrl},i}, \qquad \kappa_i\equiv\frac1{R_i},

这不是额外拼一个通信模型，而是**理论本身自然推广后的参数**。

这一点有比较强的论文价值。

## 最终研究判断

当前 EXP-1 最大的优点，是**可信度已经比早期版本高很多**。C2.1 的 budget-aware pruning、independent identity path、C3a migration、fresh test/CRN 等都已经比较扎实；当前 C3a 也严格复现了 B0.7-G2 的 `-5.3250 bits` 和 Hoeffding `U95=-1.1710`。

但是 C3b 暴露出了一个更重要的事实：

当前 Phase-PJ 不是最终论文算法。\boxed{ \text{当前 Phase-PJ 不是最终论文算法。} }

我不建议为了保住它继续做局部参数修补。更值得做的是把已经成立的 phase identity **从 next/full 的局部 theorem 升级成 arbitrary-resolution 的 phase envelope**，并把异质 U2U airtime 参数直接吸收到理论里。

这样整个研究的创新主线会从目前略显局促的：

“next-vs-full conditional refinement”\text{“next-vs-full conditional refinement”}

升级成：

 Link-aware phase-structured adaptive acquisition of multi-resolution distributed sensing evidence under a hard reporting budget \boxed{ \textbf{ Link-aware phase-structured adaptive acquisition of multi-resolution distributed sensing evidence under a hard reporting budget } }

这个定位与当前 SystemModel 原本想解决的问题更一致，也更有希望真正超过 Myopic-All，而不是绕开它。
