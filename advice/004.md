## 2. P0/P1：区域恒等式验证门是恒真式 —— 已在 C2.1b 修复 ✅

### 原问题

`run_mvsc021.py` main() 的区域恒等式检查写的是 `|gap − g_verdict|`，但
`phase_support_budget` 里：

- **C 区**：`gap = g0; g_verdict = g0` —— **字面上是同一个变量**，检查永不可能失败；
- **B 区**：`gap = Q_prog − Q_dir = −d2 + (ER1−E_dir)`，而
  `g_verdict = ER1 − E_dir − d2` —— **代数恒等**，检查同样永不可能失败。

实测：263 个支撑上 max|gap−g_verdict|=2.8e-14；把 `Q_prog` 人为 +5 破坏后
该门依旧 PASS。报告 "B: |gap−E[Y]|>1e-9 数 0 → PASS" 的表述不成立——
代码从未独立计算 E[Y] / E[min(Y,b)]。T35/T36 同样如此。

### C2.1b 修复（已实施并验证）

- **B 区**：`phase_support_budget` 现在在 B 区也计算 per-branch counterfactual
  `E_R = E[R(X2)|X1]`（仅作审计对象，**不进入** Q_prog——Q_prog 仍 = c1+E[R(X1)]），
  `g_verdict = Σw·(R1−E_R−d2)` 与 gap 的边际 tower 路径独立；
- **C 区**：`g_verdict = Q_prog − Q_dir`（策略价值形式）与 gap 的 support 形式
  `E[min(Y,b)]` 独立；
- 两侧来自不同代码路径，|gap−g_verdict|≤1e-9 **可真实失败**。sabotage 验证：
  Q_prog+5 → FAILS、E_dir+5（B 区）→ FAILS、per-branch E_R 偏差 → FAILS；
  正常路径 max |gap−g_verdict| ≈ 2.7e-13（B/C 区），远小于容差；
- **顺手修复 main() 的 g0_chk 索引 bug**：N=1 反例的 g0_chk 原用
  `br[5]=D=R1−E_R`，但 002 定理量是 `Y=R1−E_R−d2=br[6]`（注释声称的
  E[min(R1−d2,16)]）。已改为 br[6]。数值上该点恰好同为 16.000，但语义必须正确；
- T35/T36 同步为真实检查；T34 注释算术修正（c1+c2=36 而非 35）。

重跑 regression：**53/53 PASS**；SMOKE/FULL 数值与 C2.1a 逐项一致
（仅恒等式门描述更新为 "独立路径对照"）。
